# NASM x86 для олимпиадников на C++

Самостоятельный учебник по NASM IA-32: от пути программы и модели процессора до CDECL, анализа машинного кода, структур, x87 и модели объектов C++.

> Курс рассчитан на ученика с базовым C++, но без предварительного знания ассемблера, ABI, ELF и x87.

## С чего начать

1. Выполни [входную диагностику](docs/prerequisites.md).
2. При пробеле открой точный раздел [коротких повторений](docs/prerequisite_refreshers.md).
3. Прочитай [самостоятельный маршрут](docs/self_study.md).
4. Начни с [Дня 01](docs/day_01.md).
5. После главы реши соответствующую задачу в [рабочей тетради](docs/transfer_workbook.md).
6. После блока пройди одну из **шести** [контрольных точек](docs/checkpoints.md).

Курс содержит **шесть** контрольных точек с проходным баллом, критическими заданиями и новым вариантом после ошибки.

## Учебный цикл

```text
входная проверка
      ↓
короткая модель → разобранный пример → практика
                                      ↓
                               новая задача TR
                                      ↓
                         диагностический ключ
                                      ↓
                      пошаговый разбор при тупике
                                      ↓
                              новый вариант
                                      ↓
                         контрольная точка CP
```

## Что делает курс самостоятельным

Для каждого из 25 дней есть:

- проверяемые входные знания;
- короткая модель состояния;
- разобранный пример;
- практика;
- задача `TR-XX`;
- диагностический ключ;
- наблюдаемый чеклист;
- следующий шаг.

Для сложных задач `TR-13`, `TR-17` и `TR-23` добавлены [ступенчатые пошаговые разборы](docs/transfer_walkthroughs.md), которые открываются только после собственной попытки и краткого ключа.

## Единые владельцы правил

- [CDECL и регистры](docs/c_abi.md) объясняют соглашение вызова.
- [Вызов libc и выравнивание](docs/patterns/libc_alignment.md) владеет формулой padding и очистки.
- [Шесть занятий Дня 10](docs/day_10_learning_path.md) являются единственной структурой этого модуля.
- [Глоссарий](docs/glossary.md) определяет обязательные термины.

Другие страницы применяют эти правила, но не вводят альтернативные формулы.

## ИИ-наставник

[Инструкции для ИИ-наставника](docs/ai_tutor_prompts.md) являются дополнительным интерфейсом подсказок. Каноническими источниками остаются главы, наблюдаемое состояние программы и проверяемые ключи.

[Проверка ИИ-наставника](docs/ai_tutor_eval.md) отделяет структурные требования к подсказкам от реальных запусков модели.
