# NASM x86 для олимпиадников на C++

Самостоятельный учебник по NASM IA-32: от модели процессора и памяти до CDECL, анализа машинного кода, структур, x87 и модели объектов C++.

> Ты уже умеешь писать базовые программы на C++. Курс учит видеть их состояние на уровне регистров, памяти, флагов и стека.

## С чего начать

1. Проверь [входные навыки](docs/prerequisites.md): терминал, двоичную запись, указатели и структуры C++.
2. Открой [самостоятельный маршрут](docs/self_study.md).
3. Начни с [Дня 01](docs/day_01.md).
4. После каждой главы реши соответствующую задачу в [рабочей тетради](docs/transfer_workbook.md), не открывая ключ заранее.
5. После каждого блока пройди одну из **шести** [контрольных точек](docs/checkpoints.md).

Незнакомые слова собраны в [глоссарии](docs/glossary.md). Термин считается изученным не после чтения определения, а после того, как ученик применил его в трассировке или задаче.

## Что делает курс самостоятельным

Для каждого из 25 дней есть:

- проверяемые входные знания и точная ссылка для возврата;
- короткая модель состояния;
- разобранный пример;
- практика внутри главы;
- новая задача `TR-XX`;
- диагностический ключ с инвариантом, типовой ошибкой и контрпримером;
- наблюдаемый чеклист завершения;
- следующий шаг.

День 10 разделён на отдельные занятия, чтобы битовые операции, маски, округление вверх и сложные задачи не изучались одним перегруженным блоком.

## Ввод, вывод и стек

В Дне 05 изучаются только адрес, значение и память. Полный вызов `scanf`/`printf` вводится в Дне 06 вместе с минимальной моделью области вызова. Обычный стек, `call`/`ret` и кадр CDECL подробно разбираются в Днях 16–17.

Такой порядок не требует копировать необъяснённый ритуал: каждое правило, которое проверяется в задаче, до этого объясняется и трассируется.
