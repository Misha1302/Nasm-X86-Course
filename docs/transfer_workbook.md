# Рабочая тетрадь: перенос на новые задачи

Здесь по одному незнакомому заданию на каждую главу. Сначала реши полностью, затем открой [ключи](/transfer_keys). Задача закрыта, только если можешь объяснить состояние машины и нарушаемые инварианты.

## День 01 — путь программы

Расположи в правильном порядке и объясни границы ответственности: linker, CPU, assembler, loader, object file, process, executable.

## День 02 — сборка

Программа собирается `nasm -f elf32`, но линковка падает с сообщением о несовместимой архитектуре. Назови три проверки, которые отделяют ошибку исходника от ошибки 32-битного окружения.

## День 03 — инструкции и состояние

Протрассируй:

```asm
mov eax, 9
mov ebx, eax
sub eax, 4
add ebx, eax
```

Выпиши `eax`, `ebx`, изменявшиеся операнды и возможные следы во флагах после последней инструкции.

## День 04 — регистры и размеры

Дано `eax = 0x81ABCDEF`. После `mov ah, 0x10` и `mov al, 0x80` выпиши `eax`, `ax`, `ah`, `al`. Затем прочитай `al` как signed и unsigned.

## День 05 — адрес и значение

Для `x dd 17` объясни результат каждой строки независимо:

```asm
mov eax, x
mov ebx, [x]
lea ecx, [x]
mov [x], ebx
```

Какие регистры содержат адрес, а какие значение?

## День 06 — libc-вызов

Напиши полный фрагмент `scanf("%d%d", &a, &b)` и затем `printf("%d", a-b)`. После каждого вызова укажи изменение `esp` и регистры, на сохранность которых нельзя рассчитывать.

## День 07 — арифметика

В 8-битной модели вычисли `0x7F + 0x02` и `0xFF + 0x02`. Для каждого случая укажи сохранённые биты, signed-смысл, unsigned-смысл, `CF` и `OF`.

## День 08 — расширение

В памяти лежит `byte 0xA0`. Получи в `eax` сначала `160`, затем `-96`. Объясни, почему простое `mov al,[x]` не решает задачу надёжно, если старшие биты `eax` неизвестны.

## День 09 — деление

Протрассируй signed `-20 / 6`: подготовка делимого, частное и остаток. Затем объясни, какой результат даст unsigned-интерпретация тех же 32 бит.

## День 10 — биты и branchless

Построй без переходов `min(a,b)` для signed 32-bit через маску знака разности `a-b`. Обязательно укажи ограничение этого способа и тесты, на которых переполнение разности меняет знак.

## День 11 — флаги

Для каждой последовательности выпиши флаги, на которые можно опираться перед `jcc`, и объясни последнюю флагоизменяющую инструкцию:

```asm
cmp eax, ebx
mov ecx, 10
sub edx, edx
```

```asm
test eax, eax
lea ecx, [ecx+1]
```

## День 12 — сравнения

Переведи в NASM:

```cpp
if (x != 0 && (unsigned)y <= 15 && (x & 8) != 0)
    answer = 1;
```

Прыгай через тело по ложному условию.

## День 13 — control flow

Построй GOTO-form и NASM-shape:

```cpp
for (int i=0; i<n; ++i) {
    if (a[i] < 0) continue;
    if (a[i] == 0) break;
    sum += a[i];
}
```

Отдельно отметь метки проверки, шага, `continue`, `break`.

## День 14 — jump table

Дано:

```asm
sub eax, 5
cmp eax, 6
ja .default
jmp [.T + 4*eax]
.T: dd .A, .B, .B, .D, .default, .F, .A
```

Построй таблицу `индекс → исходный case → метка` и назови объединённые ветки.

## День 15 — адресация

Для `short matrix[4][7]` выведи адрес `matrix[i][j]`. Затем напиши NASM-фрагмент загрузки signed-элемента, если base находится в `edx`, `i` — в `eax`, `j` — в `ecx`.

## День 16 — стек

Пусть перед кодом `esp=0x1000`:

```asm
push 10
push 20
call f
```

Внутри `f` сразу после `call` нарисуй адреса и содержимое стека. Затем покажи состояние после `ret` и очистки двух аргументов caller-ом.

## День 17 — CDECL

Напиши функцию `int clamp_sum(int a,int b,int* out)`, которая записывает `a+b` по `out`, использует `ebx` как временный регистр и возвращает сумму в `eax`. Сохрани все обязательные регистры и покажи frame layout.

## День 18 — reverse engineering

Восстанови два возможных C-представления и перечисли подтверждённые факты:

```asm
push ebp
mov ebp, esp
mov edx, [ebp+8]
movzx eax, byte [edx]
add eax, [ebp+12]
pop ebp
ret
```

Не придумывай имена и signedness там, где листинг их не доказывает.

## День 19 — структуры

Для IA-32 оцени layout:

```cpp
struct Item {
    char tag;
    int value;
    short flags;
    Item* next;
};
```

Укажи возможные offsets, padding, `sizeof(Item)` и NASM-доступ к `p->next`.

## День 20 — startup

Объясни, почему `global main` не делает `main` ELF entry point. Назови, где посмотреть entry point и как связаны loader, `_start`, runtime и `main`.

## День 21 — memory safety

Нарисуй возможный frame с `char buf[8]`, canary, saved `ebp` и return address. Объясни отдельно, что обнаруживает canary, что запрещает NX и почему ни одна защита не делает выход за границы корректным.

## День 22 — floating point

Представь `6.625` в binary и нормализованном виде. Затем объясни, почему сравнение с фиксированным `eps` тоже не универсально для всех масштабов значений.

## День 23 — x87

Составь x87-последовательность для `(a-b)/(c+d)`. После каждой инструкции выпиши `st(0..)` и заверши корректной передачей результата в `printf("%f")`.

## День 24 — C++ object model

Проанализируй:

```asm
mov ecx, [ebp+8]
mov eax, [ecx]
mov edx, [ecx+4]
call dword [eax+8]
```

Отдели подтверждённые факты от гипотезы о `this`, `vptr`, поле и virtual call. Назови ABI-зависимые детали.

## День 25 — смешанный мини-финал

За 25 минут без справочника:

1. исправь `scanf`, которому передали `[x]`;
2. протрассируй `-13 / 5`;
3. выбери signed `jcc` для `x >= y`;
4. нарисуй frame функции с двумя аргументами и одной локальной;
5. объясни передачу x87-результата в `printf("%f")`.

После проверки выбери самый слабый инвариант и реши соответствующее задание повторно на следующий день.
