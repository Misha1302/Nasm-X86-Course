## За 30 секунд

- Адрес x86 имеет форму `[base + index*scale + displacement]`.
- Допустимый множитель `scale`: `1`, `2`, `4` или `8`.
- `mov eax,[addr]` читает память.
- `lea eax,[addr]` вычисляет адрес и память не читает.
- Адрес `a[i]` равен `base + i*sizeof(element)`.
- Двумерный C-массив хранится построчно.

## Главная модель

```text
address = base + index * scale + displacement
```

Пример:

```asm
[eax + ecx*4 + 8]
```

| Часть | Значение |
|---|---|
| база | `eax` |
| индекс | `ecx` |
| множитель | `4` |
| постоянное смещение | `8` |

Центральный инвариант:

> Адресное выражение вычисляет номер байта; только инструкция с операндом памяти читает или записывает данные по этому адресу.

---

## `mov` и `lea`

```asm
mov eax, [edx + 4*ecx]
```

означает:

```text
прочитать 4 байта по адресу edx+4*ecx
```

```asm
lea eax, [edx + 4*ecx]
```

означает:

```text
записать в eax само число edx+4*ecx
```

`lea` можно использовать и как арифметику:

```asm
lea eax, [eax + 2*eax]   ; eax = 3*eax
```

---

## Одномерный массив

```cpp
int a[5];
```

В учебной IA-32-модели `int` занимает 4 байта:

```text
&a[i] = base + 4*i
```

Если `edx` хранит начало массива, `ecx` — индекс:

```asm
lea eax, [edx + 4*ecx]   ; eax = &a[i]
mov eax, [edx + 4*ecx]   ; eax = a[i]
```

Для `short` шаг равен 2:

```asm
movsx eax, word [edx + 2*ecx]
```

Для `unsigned char` шаг равен 1:

```asm
movzx eax, byte [edx + ecx]
```

Размер элемента и вид расширения являются разными решениями.

## Двумерный массив

```cpp
int matrix[3][5];
```

Построчное размещение:

```text
linear_index = i*5 + j
address = base + 4*(i*5+j)
```

NASM:

```asm
mov eax, [i]
imul eax, 5
add eax, [j]
mov edx, [matrix + 4*eax]
```

Для `short matrix[4][7]`:

```text
address = base + 2*(i*7+j)
```

Один вариант:

```asm
; edx = base, eax = i, ecx = j
imul eax, eax, 7
add eax, ecx
movsx eax, word [edx + 2*eax]
```

## Поле и массив внутри структуры

Адрес:

```text
object_base + field_offset + index*element_size
```

Например, если массив `int values[]` начинается со смещения 8:

```asm
mov eax, [edx + 4*ecx + 8]
```

Машинный код подтверждает базу, индекс, размер и смещение. Имена структуры и поля требуют дополнительного контекста.

## Практика

### 1. Разбери адрес

```asm
mov eax, [ebx + esi*8 + 16]
```

Назови базу, индекс, множитель и смещение.

<details>
<summary>Ответ</summary>

База `ebx`, индекс `esi`, множитель `8`, смещение `16`.

</details>

### 2. Адрес или значение

Что делают инструкции?

```asm
lea eax, [edx + 4*ecx]
mov ebx, [edx + 4*ecx]
```

<details>
<summary>Ответ</summary>

Первая вычисляет адрес `a[i]`, вторая читает значение `a[i]`.

</details>

### 3. `short matrix[4][7]`

Выведи формулу адреса `matrix[i][j]`.

<details>
<summary>Ответ</summary>

```text
base + 2*(i*7+j)
```

</details>

### 4. Найди ошибку

```asm
; char a[100], ecx=i
mov eax, [a + 4*ecx]
```

<details>
<summary>Ответ</summary>

Для `char` шаг равен 1, а чтение одного элемента требует `byte`, например `movzx eax,byte [a+ecx]`.

</details>

## Типовые ошибки

| Ошибка | Почему неверно |
|---|---|
| считать скобки у `lea` чтением памяти | `lea` вычисляет адрес |
| всегда умножать индекс на 4 | размер зависит от типа элемента |
| забыть число столбцов | адрес строки вычисляется как `i*columns` |
| смешать адрес элемента и его значение | это разные состояния |
| объявить одно имя поля доказанным | листинг показывает смещение, но не исходное имя |
| требовать знания массивов без маршрута повторения | ученик не может закрыть внешний пробел |
