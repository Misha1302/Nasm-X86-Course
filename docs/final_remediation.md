# Восстановление после финального экзамена

Эта страница используется после оценки по [ключу](/final_exam_keys).

## Порядок

1. Выбери первый критический `0`.
2. Если критических нулей нет, выбери блок ниже минимума.
3. Найди первую строку, где состояние разошлось с эталоном.
4. Повтори только необходимую модель.
5. Реши новый вариант ниже без просмотра исходного ответа.
6. Через сутки повтори ещё один короткий вариант.

## Карта блоков

| Блок | Минимум | Повторить |
|---|---:|---|
| A | 12/20 | Дни 05–10, особенно адрес/значение, деление и 10A–10E |
| B | 12/20 | Дни 04, 09, 11–12, 15 |
| C | 16/24 | Дни 16–17 и канонический CDECL |
| D | 13/21 | День 18 и правило «факт отдельно от гипотезы» |
| E | 9/15 | Дни 21–24 |

## Новые варианты

### A — код и формулы

1. Вызови `printf("%d %d", x, y)` из состояния `esp%16==0`; посчитай область вызова.
2. Вычисли `ceil(31/7)` через частное и остаток.
3. Для `boxes=8` вручную посчитай задержанные номера `0,3,6` и дневной ответ.
4. Для `det=-11` получи строку `5.5`.

### B — состояние машины

1. Протрассируй `-20/6`.
2. Для `eax=A1B2C3D4h` выполни `mov ah,0; mov al,80h`.
3. Сравни `80000000h` и `0` через `jl` и `ja`.
4. Объясни `lea edx,[eax+2*ecx+6]` и `mov dx,[eax+2*ecx+6]`.

### C — стек

1. Нарисуй кадр функции с тремя аргументами и одной локальной переменной.
2. Напиши `int sub(int a,int b)`.
3. Вызови её из выровненного состояния и докажи каждый байт области вызова.

### D — анализ

Для каждого листинга сначала выпиши только машинные факты, затем две совместимые C-подобные гипотезы:

```asm
mov eax,[ebp+8]
movzx eax,word [eax+2]
```

```asm
mov eax,[ebp+8]
call eax
```

### E — модели

1. Раздели канарейку, ASLR и NX по назначению.
2. Построй x87 для `(a+b)/(c-d)` на числах `a=2,b=4,c=10,d=7`.
3. Объясни, почему `call [eax+8]` не доказывает виртуальный метод без ABI-контекста.

## Условие повторного допуска

Повторный экзамен разрешён, когда:

- новый вариант критического задания получил полный балл;
- слабый блок достиг своего минимума на новых данных;
- ученик может назвать нарушенный инвариант без просмотра ключа.
