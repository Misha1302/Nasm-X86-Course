# Восстановление после финального экзамена

Эта страница используется после оценки по [ключу](/final_exam_keys).

## Порядок

1. Выбери первый mandatory atomic skill без минимального evidence.
2. Найди первую строку, где состояние разошлось с эталоном.
3. Повтори только объяснение и обязательную практику этого навыка.
4. Реши новый структурно отличный вариант без просмотра исходного ответа.
5. Через сутки повтори короткий вариант.
6. Пересчитай решение через assessment engine.

Высокая сумма не закрывает нулевой навык. Полная готовность требует шесть контрольных точек и финал.

## Карта блоков

| Блок | Минимум | Повторить |
|---|---:|---|
| A | 12/20 | Дни 05–10, адрес/значение, деление и 10A–10E |
| B | 12/20 | Дни 04, 09, 11–12, 15 |

| D | 13/21 | День 18, факт отдельно от гипотезы |
| E | 9/15 | Дни 21–24 |

## Новые варианты

### A

1. Вызови `printf` с другим числом аргументов из состояния `esp%16==8`; посчитай область вызова.
2. Вычисли безопасный ceil без условных механизмов и проверь шесть boundary remainders.
3. Перенеси модель «Огорода» на другую периодичность блокировки.
4. Для отрицательного `det` получи десятичную половину и отдельно обработай `INT32_MIN`.

### B

1. Протрассируй другое отрицательное деление и `INT32_MIN/-1` как negative case.
2. Измени `ah`/`al` другого исходного слова.
3. Сравни значения, для которых signed/unsigned отношения различаются.
4. Раздели новый `lea` и `mov`.

### C

1. Нарисуй кадр с тремя аргументами и локальной областью.
2. Напиши новую CDECL-функцию с ранним возвратом.
3. Докажи padding для трёх аргументов и другого исходного остатка `esp`.

### D

Используй новые листинги: сначала только факты, затем минимум две совместимые гипотезы и список недоказуемых свойств.

### E

1. Раздели канарейку, ASLR и NX.
2. Построй другое дерево x87 и числовой oracle.
3. Объясни косвенный вызов без автоматического объявления виртуального метода.

## Условие повторного допуска

- новый вариант каждого отсутствовавшего mandatory skill имеет minimum evidence;
- блоки и общий порог выполнены;
- все шесть checkpoint-assessments закрыты;
- ученик называет нарушенный инвариант без ключа.
