# Короткие повторения перед курсом

Эта страница закрывает пробелы, найденные [входной диагностикой](/prerequisites). Не читай её целиком заранее: открой только нужный раздел, выполни действия и вернись к главе.

## Терминал и файлы

### Модель

```text
текущий каталог → место, относительно которого выполняются команды
файл            → именованная последовательность байтов
путь            → адрес файла в дереве каталогов
```

### Минимальные команды

```bash
pwd                 # показать текущий каталог
ls                  # показать содержимое
mkdir nasm-check    # создать каталог
cd nasm-check       # перейти в него
cd ..               # перейти на уровень выше
cat note.txt        # показать файл
```

### Проверка

В пустом каталоге выполни:

```bash
mkdir terminal-check
cd terminal-check
printf 'hello\n' > note.txt
cat note.txt
pwd
cd ..
```

Готовность подтверждена, если можешь объяснить, где создан `note.txt` и почему после `cd ..` текущий каталог изменился.

## Двоичная запись и размеры

### Степени двойки

```text
2^0 = 1
2^1 = 2
2^2 = 4
2^3 = 8
2^4 = 16
```

Двоичное число:

```text
1101₂ = 1*8 + 1*4 + 0*2 + 1*1 = 13
```

### Размеры

```text
8 бит  = 1 байт
16 бит = 2 байта
32 бита = 4 байта
```

### Проверка

1. Запиши `21` как сумму степеней двойки.
2. Представь `21` в двоичной системе.
3. Назови количество разных битовых наборов длины 8.

<details>
<summary>Ответ</summary>

```text
21 = 16 + 4 + 1 = 10101₂
8 бит дают 2^8 = 256 наборов
```

</details>

## Указатели C++

### Модель

```cpp
int x = 10;
int* p = &x;
*p = 20;
```

Отдельные объекты:

```text
x   → ячейка со значением 10, затем 20
p   → ячейка, в которой хранится адрес x
&x  → адрес x
*p  → значение по адресу, который хранится в p
```

`p` и `*p` — не одно и то же: первое является адресом, второе — данными по адресу.

### Проверка

Для:

```cpp
int a = 7;
int* q = &a;
*q += 5;
```

ответь:

1. что хранится в `q`;
2. чему равен `a`;
3. чем `q` отличается от `*q`.

<details>
<summary>Ответ</summary>

`q` хранит адрес `a`, `a` равно `12`, `*q` обозначает значение по этому адресу.

</details>

## Массивы C++

### Модель

```cpp
int a[4] = {10, 20, 30, 40};
```

Элементы лежат последовательно:

```text
&a[0] = base + 0 * sizeof(int)
&a[1] = base + 1 * sizeof(int)
&a[2] = base + 2 * sizeof(int)
```

Для учебной IA-32-модели `sizeof(int)=4`.

### Проверка

Для массива выше:

1. чему равен `a[2]`;
2. чему равен адресный сдвиг `&a[3]-base` в байтах;
3. почему индекс `4` уже находится за пределами массива.

<details>
<summary>Ответ</summary>

`a[2]=30`, адрес `a[3]` равен `base+12`, допустимые индексы — `0..3`.

</details>

## Структуры C++

### Модель

```cpp
struct Point {
    int x;
    int y;
};
```

Один объект содержит две отдельные области полей. Выражения:

```text
p.x      → поле x объекта p
ptr->y   → поле y объекта по адресу ptr
```

Запись `ptr->y` эквивалентна `(*ptr).y`.

Точные смещения, padding и выравнивание появятся в Дне 19.

### Проверка

```cpp
Point p{3, 4};
Point* ptr = &p;
ptr->x += 2;
```

Нарисуй объект до и после операции.

<details>
<summary>Ответ</summary>

```text
до:    x=3, y=4
после: x=5, y=4
```

</details>

## Научная запись

```text
12300 = 1.23 * 10^4
0.0123 = 1.23 * 10^-2
```

Для двоичной системы идея та же, но основание равно 2:

```text
101.11₂ = 1.0111₂ * 2^2
```

### Проверка

Нормализуй `110.1₂`.

<details>
<summary>Ответ</summary>

```text
110.1₂ = 1.101₂ * 2^2
```

</details>
