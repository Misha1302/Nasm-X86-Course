# День 10. Биты, маски и код без переходов

## Опора на текущую домашку

Модуль готовит к задачам Spring-01: слияние по маске, безопасное округление вверх, «Огород», «Площадь» и битовая система.

- прочитай один 32-битный набор как знаковое и беззнаковое число;

Если один пункт не получается, вернись к [Дню 09](/day_09) или начни с [сессии 10A](/day_10_learning_path#сессия-10a-побитовые-операции-и-слияние-по-маске).

---

## За 30 секунд

- `and` оставляет выбранные биты.
- `or` объединяет независимые части.
- `xor` переключает биты по маске.
- `not` инвертирует все биты.
- `shr` сдвигает вправо с нулями, `sar` копирует знаковый бит.
- Для выбора полного 32-битного значения нужна маска `0` или `FFFFFFFFh`.
- Безопасное `ceil(a/b)` можно вычислить как `q + (r != 0)`.
- Сложная задача 01-16 является отдельным необязательным challenge.

## 10A. Побитовый выбор

Для каждого разряда:

```text
mask bit = 1 → взять бит a
mask bit = 0 → взять бит b
```

Формула:

```text
result = (a & mask) | (b & ~mask)
```

NASM:

```asm
mov eax, [a]
and eax, [mask]

mov edx, [mask]
not edx
and edx, [b]

or eax, edx
```

Центральный инвариант:

> Каждый бит результата выбирается независимо соответствующим битом маски.

Маска `1` выбирает только младший бит, а не целое слово.

## 10B. Маска знака `0/-1`

```asm
mov edx, eax
sar edx, 31
```

После этого:

```text
eax >= 0 → edx = 00000000h
eax < 0  → edx = FFFFFFFFh
```

Почему не `shr`?

```asm
shr edx, 31
```

даёт `0` или `1`. Такая маска подходит для одного бита, но не для выбора всех 32 бит.

### Выбор между двумя значениями

Пусть `edx` — маска `0/-1`:

```text
result = (a & edx) | (b & ~edx)
```

### Граница разности

Иногда маску получают по знаку `a-b`. Это корректно только когда знаковая разность представима.

Контрпример:

```text
a = INT32_MIN
b = 1
```

Математически `a-b` меньше минимального `int32_t`, поэтому сохранённый старший бит не доказывает отношение `a<b`.

## 10C. Безопасное округление вверх

Для `a>=0`, `b>0`:

```text
a = q*b + r
0 <= r < b
ceil(a/b) = q + (r != 0)
```

NASM-идея:

```asm
mov eax, [a]
xor edx, edx
div dword [b]

; eax = q, edx = r
test edx, edx
setnz dl
movzx edx, dl
add eax, edx
```

Вариант без `setcc` можно построить другими изученными средствами, но сначала важна математическая модель.

Формула:

```text
(a+b-1)/b
```

допустима только когда промежуточная сумма помещается в выбранный размер.

Контрпример:

```text
a = UINT32_MAX
b = 2
```

## 10D–10E. Прикладные задачи

В «Огороде» и «Площади» запрещено прятать всю логику в одну непрозрачную формулу. Сначала выпиши именованные промежуточные значения.

Для «Огорода»:

```text
items → boxes → blocked → day
```

Для «Площади»:

```text
det → absDet → integerPart → fractionDigit
```

Каждое значение должно иметь отдельный смысл и маленький ручной тест.

## 10F. Независимые битовые системы

`and` и `xor` работают по разрядам без переносов. Поэтому одну систему над 32-битными словами можно рассматривать как 32 одинаковые однобитные системы.

Этот навык полезен, но не блокирует переход к следующей главе без отдельного требования преподавателя или экзамена.

## Практика

### 1. Слияние руками

```text
A = 11001010₂
B = 00110101₂
M = 11110000₂
```

Вычисли `(A & M) | (B & ~M)`.

<details>
<summary>Ответ</summary>

```text
11000101₂
```

Старшие четыре бита пришли из `A`, младшие — из `B`.

</details>

### 2. Найди ошибку маски

```asm
mov edx, eax
shr edx, 31
; автор считает, что edx теперь 0 или -1
```

<details>
<summary>Ответ</summary>

`shr` даёт `0` или `1`. Нужен `sar edx,31`.

</details>

### 3. Безопасный `ceil`

Для `a=14`, `b=5` найди `q`, `r` и результат округления вверх.

<details>
<summary>Ответ</summary>

```text
q=2, r=4, result=3
```

</details>

### 4. Контрпример

Почему нельзя объявить выбор по знаку `a-b` корректным для всех `int32_t`?

<details>
<summary>Ответ</summary>

Разность может переполниться. Например, `INT32_MIN-1` не представима в `int32_t`.

</details>

## Типовые ошибки

| Ошибка | Почему неверно |
|---|---|
| использовать `0/1` как маску целого слова | выбирается только один бит |
| применять знак любой разности как результат сравнения | разность может переполниться |
| всегда использовать `(a+b-1)/b` | промежуточная сумма может не поместиться |
| проходить весь День 10 одной сессией | смешиваются независимые модели |
| считать 01-16 обязательной для всех | challenge не относится к базовому порогу перехода |
| давать результат без промежуточных величин | невозможно локализовать ошибку |
