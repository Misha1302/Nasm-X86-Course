# Справочник основных инструкций NASM IA-32

> Это справочник, а не последовательная глава. Канонические правила CDECL находятся на странице [IA-32 CDECL](/c_abi), а расчёт области вызова — на странице [Вызов libc и выравнивание](/patterns/libc_alignment).

## Порядок операндов

В NASM обычно используется форма:

```asm
instruction destination, source
```

```asm
mov eax, ebx    ; eax = ebx
add eax, 5      ; eax = eax + 5
```

Метка и чтение памяти — разные действия:

```asm
mov eax, x      ; адрес x
mov eax, [x]    ; 32-битное значение по адресу x
lea eax, [x]    ; вычислить адрес x, не читать память
```

## Пересылка и размеры

| Команда | Пример | Действие |
|---|---|---|
| `mov` | `mov eax, ebx` | копирование битов |
| `mov` | `mov byte [p], al` | запись одного байта |
| `movsx` | `movsx eax, byte [p]` | знаковое расширение |
| `movzx` | `movzx eax, byte [p]` | расширение нулями |
| `lea` | `lea eax,[ebx+4*ecx]` | вычисление адресного выражения без чтения памяти |
| `push` | `push eax` | `esp-=4`, затем запись значения |
| `pop` | `pop eax` | чтение вершины, затем `esp+=4` |

## Целочисленная арифметика

| Команда | Действие | Важная граница |
|---|---|---|
| `add`, `sub` | сложение и вычитание | обновляют арифметические флаги |
| `inc`, `dec` | изменение на 1 | `inc/dec` не изменяют `CF` |
| `neg` | двоичное отрицание | `INT_MIN` остаётся тем же набором битов |
| `imul` | знаковое умножение | возможны формы с 1, 2 и 3 операндами |
| `mul` | беззнаковое `eax*src` | полный результат в `edx:eax` |
| `cdq` | знак `eax` в `edx:eax` | используется перед `idiv` 32-битного делимого |
| `idiv` | знаковое деление `edx:eax/src` | частное `eax`, остаток `edx` |
| `div` | беззнаковое деление `edx:eax/src` | для 32-битного делимого обычно `edx=0` |

```asm
mov eax, [x]
cdq
idiv dword [y]
```

```asm
mov eax, [x]
xor edx, edx
div dword [y]
```

`div/idiv` не принимают непосредственный числовой операнд: делитель должен находиться в регистре или памяти.

## Битовые операции

| Команда | Действие |
|---|---|
| `and` | оставить биты, разрешённые маской |
| `or` | объединить установленные биты |
| `xor` | установить 1 там, где биты различаются |
| `not` | инвертировать каждый бит |
| `shl` / `sal` | сдвиг влево |
| `shr` | логический сдвиг вправо, заполнение нулями |
| `sar` | арифметический сдвиг вправо, копирование знакового бита |
| `rol`, `ror` | циклический сдвиг |

Полнословная маска выбора должна быть `00000000h` или `FFFFFFFFh`, а не `0/1`.

## Флаги и переходы

`cmp a,b` обновляет флаги как `a-b`, не сохраняя разность. `test a,b` обновляет флаги как `a&b`, не меняя операнды.

| Отношение | Знаковое | Беззнаковое |
|---|---|---|
| `<` | `jl` | `jb` |
| `<=` | `jle` | `jbe` |
| `>` | `jg` | `ja` |
| `>=` | `jge` | `jae` |
| `==` | `je` / `jz` | `je` / `jz` |
| `!=` | `jne` / `jnz` | `jne` / `jnz` |

Переход читает флаги последней инструкции, которая их изменила:

```asm
cmp eax, ebx
add ecx, 1       ; флаги cmp потеряны
jl .less         ; читает флаги add
```

## `call`, `ret` и два режима примеров

### Абстрактная трассировка

Для изучения механики допустимо рассматривать:

```text
call f → положить адрес возврата и перейти в f
ret    → снять адрес возврата и перейти по нему
```

Абстрактная трассировка не является готовым ABI-совместимым вызовом: в ней могут быть опущены выравнивающие байты.

### Исполняемый CDECL-вызов

Если перед подготовкой выполняется `esp % 16 == 0`, для двух 32-битных аргументов:

```text
argument_bytes = 8
padding = 8
cleanup = 16
```

```asm
sub esp, 8
push dword [b]
push dword [a]
call sum
add esp, 16
```

Функция:

```asm
sum:
    push ebp
    mov ebp, esp
    mov eax, [ebp+8]
    add eax, [ebp+12]
    mov esp, ebp
    pop ebp
    ret
```

Карта кадра:

```text
[ebp+12] аргумент 2
[ebp+8]  аргумент 1
[ebp+4]  адрес возврата
[ebp]    сохранённый ebp
[ebp-4]  первая локальная переменная
```

Регистры `eax`, `ecx`, `edx` вызываемая функция может изменить. `ebx`, `esi`, `edi`, `ebp` она обязана восстановить, если использовала.

## Адресация

Допустимая форма адреса IA-32:

```text
base + index*scale + displacement
scale ∈ {1,2,4,8}
```

```asm
lea eax, [edx + 4*ecx + 8]  ; вычислить адрес/числовое выражение
mov eax, [edx + 4*ecx + 8]  ; прочитать dword из памяти
```

## Минимум x87

x87 имеет отдельный стек `st(0)..st(7)`.

| Команда | Точное действие |
|---|---|
| `fld qword [x]` | добавить значение на вершину |
| `fst qword [x]` | сохранить вершину без снятия |
| `fstp qword [x]` | сохранить вершину и снять её |
| `faddp st1,st0` | `st(1)=st(1)+st(0)`, затем снять вершину |
| `fsubp st1,st0` | `st(1)=st(1)-st(0)`, затем снять вершину |
| `fmulp st1,st0` | `st(1)=st(1)*st(0)`, затем снять вершину |
| `fdivp st1,st0` | `st(1)=st(1)/st(0)`, затем снять вершину |

Для `a-b`:

```asm
fld qword [a]
fld qword [b]
fsubp st1, st0
```

Для передачи `double` в `printf("%f")` из состояния `esp%16==0`:

```asm
sub esp, 12
fstp qword [esp]
push fmt
call printf
add esp, 16
```

Обычный стек `esp` и стек x87 трассируются независимо.

## Что учить первым

```text
mov, lea, add, sub, imul, cdq, div, idiv,
and, or, xor, not, shl, shr, sar,
cmp, test, jmp, je, jne, jl, jg, jb, ja,
push, pop, call, ret, movsx, movzx
```

Не заучивай таблицу целиком: находи инструкцию, восстанавливай её воздействие на состояние и возвращайся к задаче.

## Проверяемые технические границы

### `idiv`

Даже после корректного `cdq` исключение возможно не только при нулевом делителе, но и при `INT32_MIN / -1`: частное не помещается в `eax`.

### Branchless absolute value

Шаблон `(x ^ signMask) - signMask` возвращает знаковый `abs(x)` только при предусловии `x != INT32_MIN`. Без этого предусловия результат следует трактовать как 32-битную unsigned bit magnitude, а не как положительный `int32_t`.

<a id="callee-saved"></a>
### Callee-saved

Для полной IA-32 CDECL-функции недостаточно увидеть `push ebx/esi/edi`: каждый изменённый callee-saved-регистр должен быть восстановлен на каждом достижимом пути `ret`.

### Startup direction

```text
exec → loader → _start → runtime startup → main → exit
```

`main` не является ELF entry point сам по себе.
