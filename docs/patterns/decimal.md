# Паттерн: десятичные алгоритмы

## Когда нужен

Когда задача работает с десятичной записью числа:

- развернуть число;
- проверить палиндром;
- извлечь цифры;
- сложить и сократить дроби;
- вычислить НОД.

Для беззнакового значения основной механизм — деление `edx:eax` на `10`.

## Как извлечь последнюю цифру

```text
digit = x % 10
x = x / 10
```

```asm
xor edx, edx
mov ecx, 10
div ecx          ; eax = x / 10, edx = x % 10
```

`div` использует всё делимое `edx:eax`. Для обычного 32-битного беззнакового `x` перед каждой итерацией обнуляй `edx`.

## Разворот числа

```cpp
uint32_t rev = 0;
while (x != 0) {
    uint32_t digit = x % 10;
    rev = rev * 10 + digit;
    x /= 10;
}
```

```asm
xor esi, esi        ; rev = 0
mov ecx, 10

.loop:
    test eax, eax
    je .end

    xor edx, edx
    div ecx         ; eax = x / 10, edx = digit

    imul esi, 10
    add esi, edx
    jmp .loop

.end:
; esi = reversed value, если промежуточный результат поместился в 32 бита
```

Перед использованием этой схемы докажи, что `rev * 10 + digit` помещается в выбранный тип. Для произвольного `uint32_t` разворот может потребовать больше 32 бит.

## Палиндром

Число является палиндромом, если его нормализованная десятичная запись совпадает с разворотом:

```text
is_palindrome(x) = reverse_decimal(x) == x
```

Сохрани исходное число до разрушительного цикла деления. Для `x = 0` функция разворота обычно возвращает `0`.

Если задача требует выполнить ровно `N` преобразований, не заменяй это условие проверкой «палиндром встретился раньше»: это другая задача.

## НОД через алгоритм Евклида

Для беззнаковых `a` и `b`:

```cpp
while (b != 0) {
    uint32_t r = a % b;
    a = b;
    b = r;
}
```

```asm
; eax = a
; ebx = b
.loop:
    test ebx, ebx
    je .end

    xor edx, edx
    div ebx          ; edx = a % b

    mov eax, ebx
    mov ebx, edx
    jmp .loop

.end:
; eax = gcd
```

Если это CDECL-функция, сохрани и восстанови `ebx`.

## Сложение дробей

Для текущей дроби `num / den` и новой дроби `x / y`:

```text
new_num = num * y + x * den
new_den = den * y
```

Затем:

```text
g = gcd(abs(new_num), abs(new_den))
num = new_num / g
den = new_den / g
```

Нормализуй знак так, чтобы знаменатель был положительным. Проверь деление на ноль и диапазон промежуточных произведений: даже если итог помещается в 32 бита, `num*y` или `den*y` могут переполниться. При необходимости используй 64-битные промежуточные значения или сокращай множители до умножения.

## Частые ошибки

| Ошибка | Почему плохо |
|---|---|
| забыть подготовить `edx` перед `div` | делится не `eax`, а пара `edx:eax` |
| потерять исходное число | разворот разрушает рабочую копию |
| не проверить переполнение `rev * 10 + digit` | результат молча обрежется |
| считать `0` неописанным случаем | палиндром и длина записи становятся неоднозначными |
| не нормализовать знак знаменателя | эквивалентные дроби печатаются в разных формах |
| умножать числители и знаменатели без оценки диапазона | промежуточный результат может переполниться |
| использовать `idiv` без модели знака | подготовка `edx:eax` для signed и unsigned различается |

## Мини-практика

Разверни руками `120`:

```text
120 -> digit 0 -> rev 0
12  -> digit 2 -> rev 2
1   -> digit 1 -> rev 21
```

Объясни, почему результат `21`, а не `021`, и найди минимальное число, разворот которого не помещается в выбранный 32-битный тип.
