# Дополнительно: многоразрядное произведение

::: warning
Это отдельная дополнительная тема. Она требует уверенного владения `mul`, `add/adc`, CDECL и ручным десятичным выводом.
:::

## Когда нужен

Когда результат не помещается в 32 бита и может не помещаться даже в `edx:eax`.

Произведение трёх 32-битных величин может потребовать до 96 бит:

```text
32 бита × 32 бита × 32 бита -> до 96 бит
```

Поэтому нельзя сохранить только `eax` или предположить, что 64 бит всегда достаточно.

## Представление

Храним неотрицательную величину тремя 32-битными словами:

```text
value = high : mid : low
```

```text
low  — младшие 32 бита
mid  — следующие 32 бита
high — старшие 32 бита
```

Это система счисления с основанием `2^32`.

## План знакового произведения

1. Определить знак результата.
2. Получить беззнаковые модули всех множителей как битовые величины.
3. Перемножить модули с переносами.
4. Отдельно обработать ноль.
5. Напечатать знак, если результат отрицательный.
6. Вывести 96-битный модуль в десятичном виде.

Не вычисляй `abs(INT32_MIN)` в знаковом 32-битном типе: `2147483648` в нём не представимо. Модуль надо получать как беззнаковый битовый шаблон дополнительного кода или в более широком типе.

## Знак результата

Результат отрицателен, если отрицательных множителей нечётное число:

```text
negative = sign(a) xor sign(b) xor sign(c)
```

Если хотя бы один множитель равен нулю, итоговый знак при выводе должен быть обычным нулём без `-`.

## Умножение 32×32

```asm
mov eax, [a_magnitude]
mul dword [b_magnitude]
; edx:eax = a_magnitude * b_magnitude
```

После этого имеется 64-битное значение:

```text
p = p_hi : p_lo
```

## Умножение 64×32 -> 96 бит

Разложение:

```text
(p_hi * 2^32 + p_lo) * c
= (p_lo * c) + (p_hi * c) * 2^32
```

Нужно выполнить два `mul`, сложить пересекающиеся слова и перенести флаг через `adc`:

```text
p_lo * c -> low и нижняя часть mid
p_hi * c -> добавка к mid и high
```

После каждого шага зафиксируй, какой регистр владеет `low`, `mid`, `high`; `mul` перезаписывает `edx:eax`.

## Деление многоразрядного числа на 10

Для десятичного вывода повторяем деление `high:mid:low` на `10` сверху вниз:

```text
remainder = 0
for word in [high, mid, low]:
    current = remainder : word
    quotient_word = current / 10
    remainder = current % 10
```

На каждой итерации:

```asm
; edx = remainder предыдущего слова, eax = текущее слово
div ecx             ; ecx = 10
; eax = слово частного, edx = новый остаток 0..9
```

Частное записывается обратно в `high`, `mid`, `low`. Полученный остаток — очередная десятичная цифра, начиная с конца.

## Инварианты

После каждого умножения:

```text
high:mid:low равно точному произведению уже обработанных модулей.
```

После обработки каждого слова при делении:

```text
0 <= remainder < 10
обработанный префикс восстановим как quotient_prefix * 10 + remainder.
```

## Частые ошибки

| Ошибка | Почему плохо |
|---|---|
| оставить только `eax` | результат обрезается до 32 бит |
| считать `edx:eax` достаточным для трёх множителей | точный результат может занимать 96 бит |
| потерять `p_hi` при втором `mul` | `mul` перезаписывает `edx:eax` |
| забыть `adc` | перенос между словами теряется |
| вычислять знаковый `abs(INT32_MIN)` | возникает переполнение до начала умножения |
| передавать 96-битное число в `%lld` | формат libc принимает только 64-битное значение |
| не обработать ноль | цикл печати может не вывести ни одной цифры |
| печатать `-0` | знак не нормализован после проверки нуля |

## Мини-практика

Объясни знак произведения:

```text
-234234 * -2394729 * -12323
```

Затем выпиши два частичных произведения для `(p_hi:p_lo) * c` и укажи точное место, где нужен `adc`.
