# Финальный экзамен NASM IA-32 — версия без ответов

> Не открывай [ключ](/final_exam_keys) до завершения всех заданий и фиксации времени.

## Контракт

- Время: 90 минут.
- Максимум: 100 баллов.
- Общий проход: не менее 80.
- Минимумы блоков: `A≥12`, `B≥12`, `C≥16`, `D≥13`, `E≥9`.
- Критические задания: `A1`, `A2`, `B1`, `C1`, `C3`, `D1`, `E2`.
- Ноль за critical task блокирует зачёт независимо от суммы.
- Кроме суммы и critical rules, каждый mandatory atomic skill должен иметь minimum evidence. Поэтому нули `A4`, `C2`, `E1` и `E3` также блокируют полную готовность.
- Частичная ошибка закрывается новым структурно отличным вариантом, если это требует assessment contract.
- Сессия 10F и задача 01-16 — bonus-only и не входят в обязательные 100 баллов.

Финальная попытка доказывает только собственную рубрику. Полная готовность курса определяется композицией `CP1 + CP2 + CP3 + CP4 + CP5 + CP6 + FINAL`.

## Блок A — написание кода и формул, 20 баллов

### A1. `scanf`: адрес, порядок и область вызова — 5 баллов

В начале фрагмента `esp % 16 == 0`. Напиши полный вызов:

```c
scanf("%d%d", &a, &b);
```

Укажи:

- порядок аргументов;
- `argument_bytes`;
- `padding`;
- `cleanup`;
- почему используются `a` и `b`, а не `[a]` и `[b]`.

### A2. Безопасное округление вверх — 5 баллов

Для `a>=0`, `b>0` напиши NASM-схему вычисления `ceil(a/b)`, которая не создаёт сумму `a+b-1` и не использует `jcc`, `setcc` или `cmov`. Укажи регистры частного и остатка после `div` и докажи машинный способ получить `0/1` из ненулевого остатка.

### A3. «Огород» — 5 баллов

Выведи формулы:

```text
items
boxes
blocked
dayAnswer
```

Затем опиши выбор между ночным и дневным ответом через маску `0/-1`. Отдельно назови две возможные точки переполнения.

### A4. Площадь треугольника — 5 баллов

Для удвоенной ориентированной площади `det` выведи:

```text
absDet
integerPart
fractionDigit
```

Результат должен печататься с одной цифрой после точки без x87. Объясни границу `INT32_MIN` и выбранный тип результата.

## Блок B — чтение состояния машины, 20 баллов

### B1. Знаковое деление — 5 баллов

Протрассируй:

```asm
mov eax, -13
cdq
mov ecx, 5
idiv ecx
```

Выпиши `edx:eax` до деления, частное и остаток. Отдельно объясни, почему корректный `cdq` и ненулевой делитель не спасают случай `INT32_MIN / -1`.

### B2. Перекрывающиеся регистры — 5 баллов

Начальное состояние:

```text
eax = 0x80FF1020
```

После:

```asm
mov ah, 0x7F
mov al, 0x90
```

выпиши `eax`, `ax`, `ah`, `al`, а также знаковое и беззнаковое значение `al`.

### B3. Флаги и интерпретация — 5 баллов

Для `eax=FFFFFFFFh`, `ebx=1` после `cmp eax,ebx` объясни результаты `jl`, `ja` и причину различия.

### B4. Адресация — 5 баллов

Объясни различие:

```asm
lea eax, [edx + 4*ecx + 8]
mov eax, [edx + 4*ecx + 8]
```

Назови подтверждённые действия, не придумывая тип массива без контекста.

## Блок C — стек и функции, 24 балла

### C1. Кадр стека — 8 баллов

Нарисуй кадр функции с двумя аргументами и двумя локальными `int` после:

```asm
push ebp
mov ebp, esp
sub esp, 8
```

Отметь `[ebp]`, `[ebp+4]`, `[ebp+8]`, `[ebp+12]`, `[ebp-4]`, `[ebp-8]`.

### C2. Функция `sum` — 8 баллов

Напиши CDECL-функцию:

```c
int sum(int a, int b);
```

Она должна вернуть сумму в `eax`, восстановить кадр и не нарушить callee-saved contract.

### C3. ABI-совместимый вызов `sum` — 8 баллов

До подготовки вызова выполняется `esp % 16 == 0`. Напиши исполняемый вызов `sum(a,b)` и докажи:

```text
argument_bytes
padding
esp % 16 непосредственно перед call
cleanup после возврата
```

Абстрактная трассировка без padding здесь не принимается.

## Блок D — анализ машинного кода, 21 балл

Для каждого листинга раздели ответ на подтверждённые факты, допустимую C-подобную гипотезу и недоказуемые свойства.

### D1. Сложение аргументов — 7 баллов

```asm
f:
    push ebp
    mov ebp, esp
    mov eax, [ebp+8]
    add eax, [ebp+12]
    pop ebp
    ret
```

### D2. Запись через указатель — 7 баллов

```asm
f:
    push ebp
    mov ebp, esp
    mov eax, [ebp+8]
    mov edx, [ebp+12]
    mov [eax], edx
    pop ebp
    ret
```

### D3. Чтение знакового байта — 7 баллов

```asm
f:
    push ebp
    mov ebp, esp
    mov edx, [ebp+8]
    movsx eax, byte [edx]
    pop ebp
    ret
```

## Блок E — объяснение моделей, 15 баллов

### E1. Безопасность памяти — 5 баллов

Объясни отдельно:

- что обнаруживает стековая канарейка;
- что запрещает NX;
- почему выход за границы остаётся UB и не обязан сразу завершить программу.

### E2. x87 и `%f` — 5 баллов

Составь последовательность для `(a-b)/c`, выпиши `st(0..)` после каждой инструкции и затем передай результат в `printf("%f")` из состояния `esp % 16 == 0`.

Укажи размер `double`, padding и cleanup.

### E3. Объект C++ и косвенный вызов — 5 баллов

Для:

```asm
mov ecx, [ebp+8]
mov eax, [ecx]
call dword [eax+8]
```

раздели:

1. машинные факты;
2. гипотезу `this/vptr/ячейка виртуального метода`;
3. ABI-зависимые детали.

## Необязательный бонус 10F — 0 баллов ядра

**Задача 01-16.** Объясни, почему систему над `&` и `^` можно решать независимо по каждому биту, и перечисли четыре кандидата `(x_bit,y_bit)`. Бонус не компенсирует провал обязательного навыка.
