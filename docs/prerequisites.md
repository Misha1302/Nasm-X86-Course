# Входная диагностика

Курс рассчитан на ученика, который уже писал базовые программы на C++, но ещё не изучал ассемблер и устройство IA-32.

Не оценивай себя словами «знаю» или «не знаю». Выполни действия ниже. Если действие не получается, пройди короткое повторение до Дня 01.

## 1. Терминал

В пустом учебном каталоге выполни:

```bash
pwd
ls
mkdir nasm-check
cd nasm-check
printf 'hello\n' > note.txt
cat note.txt
```

Готовность подтверждена, если ты можешь объяснить, какой каталог текущий, какой файл создан и как вернуться на уровень выше командой `cd ..`.

## 2. Числа и степени двойки

Без калькулятора:

1. представь `13` как сумму степеней двойки;
2. запиши `13` в двоичной системе;
3. назови количество значений, представимых 8 битами;
4. объясни, сколько байтов в 32 битах.

<details>
<summary>Проверка</summary>

```text
13 = 8 + 4 + 1 = 1101₂
8 бит дают 2^8 = 256 наборов битов
32 бита = 4 байта
```

</details>

## 3. C++: выражения и типы

Объясни результат:

```cpp
int a = 7;
int b = 3;
int x = a + b * 2;
```

Затем назови разницу между `int` и `unsigned int` на уровне допустимых числовых значений. Детали двоичного дополнительного кода пока не требуются.

## 4. C++: указатель

Для кода:

```cpp
int x = 10;
int* p = &x;
*p = 20;
```

объясни отдельно:

- что хранится в `x`;
- что хранится в `p`;
- что означает `&x`;
- что означает `*p`;
- чему равен `x` после выполнения.

Если эти различия неустойчивы, сначала повтори указатели: в Дне 05 адрес и значение станут центральной моделью.

## 5. C++: массив

Для:

```cpp
int a[4] = {10, 20, 30, 40};
```

объясни:

- чему равен `a[2]`;
- почему допустимые индексы — `0..3`;
- чем значение элемента отличается от его адреса;
- почему соседние `int` занимают несколько соседних байтов.

## 6. C++: структура

Для:

```cpp
struct Point {
    int x;
    int y;
};
```

нарисуй один объект как последовательность двух полей и объясни выражения `p.x` и `ptr->y`.

Точные смещения и выравнивание будут изучаться в Дне 19.

## 7. Научная запись

Преобразуй:

```text
12300 = 1.23 × 10^4
0.0123 = 1.23 × 10^-2
```

Если это непонятно, повтори степени: они понадобятся только перед Днём 22.

## Решение о старте

Можно начинать День 01, если уверенно выполнены разделы 1–3. Разделы 4–6 можно повторить перед соответствующими главами. Научная запись нужна только к блоку чисел с плавающей точкой.

Незнакомые слова проверяй по [глоссарию](/glossary), но не заменяй определением выполнение задачи.
