# Входная диагностика

Курс рассчитан на ученика, который уже писал базовые программы на C++, но ещё не изучал ассемблер, ABI и устройство IA-32.

Не отвечай «знаю». Выполни действия. Если проверка не пройдена, открой точный раздел [короткого повторения](/prerequisite_refreshers), закрой пробел и повтори действие.

## 1. Терминал

В пустом учебном каталоге выполни:

```bash
pwd
ls
mkdir nasm-check
cd nasm-check
printf 'hello\n' > note.txt
cat note.txt
cd ..
```

Готовность подтверждена, если можешь объяснить, где создан файл и как изменился текущий каталог.

Не получилось: [повтори терминал и файлы](/prerequisite_refreshers#терминал-и-файлы).

## 2. Числа и степени двойки

Без калькулятора:

1. представь `13` как сумму степеней двойки;
2. запиши `13` в двоичной системе;
3. назови количество разных 8-битных наборов;
4. объясни, сколько байтов в 32 битах.

<details>
<summary>Проверка</summary>

```text
13 = 8 + 4 + 1 = 1101₂
8 бит дают 2^8 = 256 наборов
32 бита = 4 байта
```

</details>

Не получилось: [повтори двоичную запись и размеры](/prerequisite_refreshers#двоичная-запись-и-размеры).

## 3. C++: выражения и типы

Объясни результат:

```cpp
int a = 7;
int b = 3;
int x = a + b * 2;
```

Затем назови различие между `int` и `unsigned int` на уровне допустимых значений. Детали дополнительного кода пока не требуются.

## 4. C++: указатель

```cpp
int x = 10;
int* p = &x;
*p = 20;
```

Объясни отдельно:

- что хранится в `x`;
- что хранится в `p`;
- что означает `&x`;
- что означает `*p`;
- чему равен `x` после выполнения.

Не получилось: [повтори указатели](/prerequisite_refreshers#указатели-c).

## 5. C++: массив

```cpp
int a[4] = {10, 20, 30, 40};
```

Объясни:

- чему равен `a[2]`;
- почему допустимые индексы — `0..3`;
- чем значение элемента отличается от его адреса;
- на сколько байтов отличаются адреса соседних `int` в учебной модели.

Не получилось: [повтори массивы](/prerequisite_refreshers#массивы-c).

## 6. C++: структура

```cpp
struct Point {
    int x;
    int y;
};
```

Нарисуй один объект как два поля и объясни выражения `p.x`, `ptr->y`, `(*ptr).y`.

Не получилось: [повтори структуры](/prerequisite_refreshers#структуры-c).

## 7. Научная запись

Преобразуй:

```text
12300 = 1.23 * 10^4
0.0123 = 1.23 * 10^-2
```

Не получилось: [повтори научную запись](/prerequisite_refreshers#научная-запись).

## Решение о старте

Можно начинать День 01, если уверенно выполнены разделы 1–3.

Перед соответствующими блоками обязательно вернись к диагностике:

| Перед темой | Нужна проверка |
|---|---|
| День 05 | указатели: адрес против значения |
| День 15 | массивы и размер элемента |
| День 19 | указатели и структуры |
| День 22 | степени и научная запись |

Незнакомые термины проверяй по [глоссарию](/glossary), но определение не заменяет выполнение задачи.
