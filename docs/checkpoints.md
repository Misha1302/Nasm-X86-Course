# Контрольные точки курса

Контрольная точка нужна не для получения оценки, а для решения: можно ли идти дальше без скрытого пробела. Выполняй задания без справочника, затем сверяй ответы с соответствующими главами.

Каждый checkpoint проверяет четыре разных действия:

```text
trace → заполнить пропуски → написать самому → найти баг
```

## Как оценивать

- **4/4** — переходи дальше.
- **3/4** — исправь ошибку и повтори одно похожее задание.
- **0–2/4** — вернись к указанным дням; следующий блок опирается на эту модель.
- Ошибка в обязательном инварианте (`x/[x]`, signed/unsigned, `edx:eax`, баланс `esp`) блокирует переход независимо от суммы.

## Checkpoint 1 — после Дня 04

Проверяет дни 01–04.

1. **Trace:** после `mov eax, 5; mov ebx, eax; add eax, 2` выпиши `eax` и `ebx`.
2. **Пропуски:** дополни `mov ___, [x]`, чтобы загрузить значение в `eax`.
3. **Напиши:** переведи `a = b + 7` в четыре машинных шага с памятью.
4. **Найди баг:** объясни, почему `mov [a], [b]` не является обычной допустимой формой.

Повторять: дни 03–04.

## Checkpoint 2 — после Дня 10

Проверяет память, ввод/вывод, арифметику, расширение, деление и биты.

1. **Trace:** выполни руками `eax=-7; cdq; idiv 3` и запиши `eax/edx`.
2. **Пропуски:** восстанови `scanf("%d", &x)` и правильную очистку стека.
3. **Напиши:** собери `(a & mask) | (b & ~mask)` без переходов.
4. **Найди баг:** почему `shr edx, 31` ломает маску знака для отрицательного числа?

Повторять: дни 05–10.

## Checkpoint 3 — после Дня 15

Проверяет флаги, условия, циклы, switch и адресацию.

1. **Trace:** для `eax=FFFFFFFFh`, `ebx=1` объясни результаты signed `jl` и unsigned `ja`.
2. **Пропуски:** дополни проверку нечётности через `test`.
3. **Напиши:** переведи цикл `for (i=0; i<n; ++i) sum += a[i]` в GOTO-shape и адресную формулу.
4. **Найди баг:** между `cmp` и `jl` стоит `add ecx,1`; объясни последствие.

Повторять: дни 11–15.

## Checkpoint 4 — после Дня 19

Проверяет стек, CDECL, reverse engineering и структуры.

1. **Trace:** нарисуй стек после двух аргументов и `call`.
2. **Пропуски:** восстанови классический пролог/эпилог.
3. **Напиши:** функция `sum(int a,int b)` с return в `eax`.
4. **Найди баг:** функция изменила `ebx` и не восстановила его; объясни нарушение контракта.

Повторять: дни 16–19.

## Checkpoint 5 — после Дня 23

Проверяет startup, memory safety, floating point и x87.

1. **Trace:** состояние `st(0..)` после `fld a; fld b; faddp`.
2. **Пропуски:** сохрани результат для `printf("%f")` правильного размера.
3. **Напиши:** объясни путь `_start → runtime → main` в пяти строках.
4. **Найди баг:** почему out-of-bounds запись может повредить return address, но не обязана сразу уронить программу?

Повторять: дни 20–23.
