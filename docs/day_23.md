## За 30 секунд

- x87 имеет отдельный стек из восьми регистров `st(0)..st(7)`.
- `fld` добавляет значение на вершину.
- `fstp` сохраняет вершину в память и снимает её.
- Операции с суффиксом `p` обычно уменьшают глубину стека на один.
- Для вычитания и деления порядок операндов обязателен.
- `printf("%f")` получает 8-байтный `double`.
- Обычный стек `esp` и стек x87 — разные состояния, которые нужно трассировать отдельно.

## Минимум после главы

- сохранить результат как `qword` для `printf("%f")`;

## Два разных стека

В программе одновременно существуют:

1. обычный стек в памяти, вершина которого задаётся `esp`;
2. стек регистров x87, вершина которого называется `st(0)`.

```text
обычный стек: аргументы, адреса возврата, временные байты
x87-стек:     вещественные операнды и промежуточные результаты
```

Команда `fld` меняет x87-стек, но не `esp`.

Команда `push eax` меняет обычный стек, но не x87-стек.

Центральный инвариант:

> После законченного выражения глубина x87-стека и значение `esp` должны соответствовать ожидаемому состоянию независимо друг от друга.

## Стек x87

x87 содержит восемь логических позиций:

```text
st(0) — вершина
st(1)
st(2)
...
st(7)
```

После:

```asm
fld qword [a]
fld qword [b]
```

состояние:

```text
st(0) = b
st(1) = a
глубина = 2
```

Новые значения всегда появляются в `st(0)`, а старые сдвигаются глубже.

---

## Загрузка и сохранение

### `fld`

```asm
fld dword [x]    ; загрузить 32-битный float
fld qword [y]    ; загрузить 64-битный double
```

Обе команды добавляют одно значение в x87-стек.

### `fst`

```asm
fst qword [result]
```

Сохраняет `st(0)`, но не меняет глубину.

### `fstp`

```asm
fstp qword [result]
```

Сохраняет `st(0)` и снимает его:

```text
глубина = глубина - 1
```

Если результат больше не нужен в x87, обычно выбирается `fstp`, чтобы не оставлять лишнее значение.

## Разобранный пример `(a+b)*c`

Код:

```asm
fld qword [a]
fld qword [b]
faddp st1, st0
fld qword [c]
fmulp st1, st0
fstp qword [answer]
```

Трассировка:

| Инструкция | Состояние x87 | Глубина |
|---|---|---:|
| начало | пусто | 0 |
| `fld a` | `st(0)=a` | 1 |
| `fld b` | `st(0)=b`, `st(1)=a` | 2 |
| `faddp st1,st0` | `st(0)=a+b` | 1 |
| `fld c` | `st(0)=c`, `st(1)=a+b` | 2 |
| `fmulp st1,st0` | `st(0)=(a+b)*c` | 1 |
| `fstp answer` | пусто | 0 |

Глубина вернулась к нулю.

## Некоммутативные операции

Сложение и умножение не различают перестановку операндов. Вычитание и деление различают.

### `a-b`

```asm
fld qword [a]
fld qword [b]
fsubp st1, st0
```

Перед `fsubp`:

```text
st(0)=b
st(1)=a
```

Явная форма означает:

```text
st(1) = st(1) - st(0) = a - b
затем pop
```

После операции:

```text
st(0)=a-b
```

### `a/b`

```asm
fld qword [a]
fld qword [b]
fdivp st1, st0
```

Результат:

```text
st(0)=a/b
```

Проверяй порядок несимметричными числами:

```text
a=10, b=2
ожидается a-b=8 и a/b=5
```

Результаты `-8` или `0.2` сразу показывают обратный порядок.

## Выражение `(a-b)/(c+d)`

```asm
fld qword [a]
fld qword [b]
fsubp st1, st0      ; a-b

fld qword [c]
fld qword [d]
faddp st1, st0      ; c+d

fdivp st1, st0      ; (a-b)/(c+d)
```

Трассировка:

| После шага | `st(0)` | `st(1)` | Глубина |
|---|---|---|---:|
| `fsubp` | `a-b` | — | 1 |
| `fld c` | `c` | `a-b` | 2 |
| `fld d` | `d` | `c` | 3 |
| `faddp` | `c+d` | `a-b` | 2 |
| `fdivp` | `(a-b)/(c+d)` | — | 1 |

---

## Почему `%f` получает `double`

`printf` — функция с переменным числом аргументов. При таком вызове значение типа `float` передаётся как `double`.

Следовательно:

```text
%f → 8 байт → qword
```

Неверно сохранять только четыре байта:

```asm
fstp dword [esp]
```

`printf` прочитает восемь байтов и захватит чужие данные.

---

## Корректная передача результата в `printf`

Предположим, что перед подготовкой выполняется:

```text
esp % 16 == 0
```

Аргументы:

```text
строка формата: 4 байта
значение double: 8 байт
итого аргументов: 12 байт
```

Для кратности 16 нужен ещё 4-байтный участок выравнивания.

Непрерывная область вызова:

```asm
sub esp, 12          ; 4 padding + 8 bytes for double
fstp qword [esp]     ; double занимает [esp..esp+7]
push fmt             ; ещё 4 байта
call printf
add esp, 16          ; удалить padding, double и fmt
```

Проверка обычного стека:

| Шаг | Изменение `esp` |
|---|---:|
| начало | `0` |
| `sub esp,12` | `-12` |
| `push fmt` | `-16` |
| перед `call` | `-16`, кратно 16 |
| `add esp,16` после возврата | `0` |

Здесь нет отдельной последовательности `sub esp,8` / `add esp,12`: она не содержит необходимых четырёх выравнивающих байтов при принятом начальном состоянии.

---

## Полный пример

```asm
section .data
    fmt db "%f", 10, 0
    a dq 10.0
    b dq 4.0
    c dq 3.0

section .text
    extern printf
    global main

main:
    push ebp
    mov ebp, esp
    and esp, -16

    fld qword [a]
    fld qword [b]
    fsubp st1, st0
    fld qword [c]
    fdivp st1, st0      ; (a-b)/c = 2.0

    sub esp, 12
    fstp qword [esp]
    push fmt
    call printf
    add esp, 16

    mov esp, ebp
    pop ebp
    xor eax, eax
    ret
```

Перед `printf` x87-стек содержит один результат. `fstp` передаёт его в обычную область вызова и возвращает глубину x87 к нулю.

## Практика

### 1. Глубина

Что находится в стеке после:

```asm
fld qword [x]
fld qword [y]
faddp st1, st0
```

<details>
<summary>Ответ</summary>

```text
st(0)=x+y
глубина=1
```

</details>

### 2. Порядок деления

Напиши последовательность для `a/b` и проверь её на `a=10`, `b=2`.

<details>
<summary>Ответ</summary>

```asm
fld qword [a]
fld qword [b]
fdivp st1, st0
```

Результат в `st(0)` равен `5`.

</details>

### 3. Найди две ошибки

```asm
sub esp, 8
fstp dword [esp]
push fmt
call printf
add esp, 12
```

<details>
<summary>Ответ</summary>

`%f` ожидает 8-байтный `double`, поэтому нужен `fstp qword [esp]`. При исходном `esp%16==0` область аргументов занимает 12 байт и требует ещё 4 байта выравнивания: корректный шаблон использует `sub esp,12` и `add esp,16`.

</details>

### 4. Полная трассировка

Для `(a-b)/(c+d)` выпиши `st(0..)` после каждой инструкции и проверь числами `a=10`, `b=4`, `c=1`, `d=2`.

<details>
<summary>Ответ</summary>

```text
(a-b)/(c+d) = 6/3 = 2
```

Глубина перед сохранением результата равна `1`.

</details>

## Типовые ошибки

| Ошибка | Почему неверно |
|---|---|
| считать `st(0)..st(7)` независимыми именованными регистрами | `fld` меняет логические позиции стека |
| забыть `p` и оставить лишний операнд | глубина растёт и последующие операции используют не те значения |
| перепутать `a/b` и `b/a` | деление некоммутативно |
| передать `%f` через `dword` | `printf` ожидает 8-байтный `double` |
| смешать глубину x87 и значение `esp` | это два независимых стека |
| удалить 12 байт после подготовки 16 | обычный стек остаётся смещённым |
