# 01-14. Огород

## Условие

Есть поле `N * M`. С каждого квадратного метра собрали `K` свёкол.

Свёклу разложили по коробкам по `D` штук. Последняя коробка может быть неполной.

Границу проходят 8 марта в `X` часов `Y` минут.

- ночью с `00:00` до `05:59` проходят все коробки;
- в другое время коробки нумеруют с нуля и задерживают номера, кратные 3.

Нужно вывести количество коробок, которые прошли границу.

Запрещены условные передачи, условное управление и явное использование `EFLAGS`.

## Ввод

```text
N M K D X Y
```

## Вывод

Одно число: количество прошедших коробок.

## Ограничения

- `1 <= N, M <= 1000`;
- `0 <= K <= 1000`;
- `1 <= D <= 10000`;
- `0 <= X <= 23`;
- `0 <= Y <= 59`.

<a id="required-solution"></a>
## Решение

### 1. Считаем урожай

```text
items = N * M * K
```

Произведение проверяется в достаточно широком представлении: максимальное значение по ограничениям равно `10^9` и помещается в unsigned 32-bit, но промежуточный контракт всё равно фиксируется явно.

### 2. Считаем коробки без переполняющейся суммы

Пусть после беззнакового `div D`:

```text
q = items / D
r = items % D
boxes = q + nonzero(r)
```

Машинный признак ненулевого беззнакового остатка уже объяснён в [Дне 10](/day_10#10c-безопасное-округление-вверх):

```asm
; eax = q, edx = r
mov ecx, edx
neg ecx
or ecx, edx
shr ecx, 31       ; ecx = 0 при r=0, иначе 1
add eax, ecx      ; eax = boxes
```

Этот способ не использует `test`, `setcc`, `cmov`, `jcc` или скрытое чтение `EFLAGS`.

### 3. Считаем дневной ответ

Днём задерживают коробки с номерами `0,3,6,9,...`. Их количество среди `0..boxes-1` также вычисляется через частное и остаток:

```text
blocked_q = boxes / 3
blocked_r = boxes % 3
blocked = blocked_q + nonzero(blocked_r)
dayAnswer = boxes - blocked
```

Тот же машинный шаблон `r | -r` превращает `blocked_r` в `0/1` без условных механизмов.

### 4. Считаем ночной ответ

```text
nightAnswer = boxes
```

### 5. Выбираем без `if`

Ночь определяется только часом. Так как `X` находится в `0..23`, разность `X-6` не переполняется:

```asm
mov ecx, [X]
sub ecx, 6
sar ecx, 31        ; ecx = -1 если X < 6, иначе 0
```

Дальше:

```text
answer = (nightAnswer & mask) | (dayAnswer & ~mask)
```

## Схема на NASM

```asm
; eax = items = N * M * K
mov eax, [N]
imul eax, [M]
imul eax, [K]

; boxes = items / D + nonzero(items % D)
xor edx, edx
div dword [D]
mov ecx, edx
neg ecx
or ecx, edx
shr ecx, 31
add eax, ecx
mov [boxes], eax

; blocked = boxes / 3 + nonzero(boxes % 3)
xor edx, edx
mov ecx, 3
div ecx
mov ecx, edx
neg ecx
or ecx, edx
shr ecx, 31
add eax, ecx
; eax = blocked
```

Обязательные boundary tests для преобразования остатка: `0`, `1`, `2`, `0x7FFFFFFF`, `0x80000000`, `0xFFFFFFFF`.

## Ошибки

| Ошибка | Почему плохо |
|---|---|
| `boxes = items / D` | забыта неполная последняя коробка |
| `(items + D - 1) / D` без доказательства | промежуточная сумма может переполниться |
| считать задержанные как `boxes / 3` | коробка `0` тоже кратна трём |
| использовать `test/setcc/jcc/cmov` | обязательная версия не зависит от будущего условного материала |
| сделать маску выбора `0/1` | для выбора всего числа нужна `0/FFFFFFFFh` |
| использовать `Y` для ночи | весь час `0..5` ночной, минуты не меняют решение |
