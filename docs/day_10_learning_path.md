# День 10 как шесть самостоятельных занятий

[Основная глава Дня 10](/day_10) объединяет несколько разных навыков. Этот маршрут не добавляет новую теорию: он делит материал на короткие занятия с отдельными условиями перехода.

## Правило перехода

Не переходи к следующей сессии, пока не можешь выполнить мини-проверку без подсказки и объяснить центральный инвариант.

Просмотренное решение не считается закрытием занятия.

## Сессия 10A — побитовые операции

Пройди:

- `and`, `or`, `xor`, `not`;
- `shl`, `shr`, `sar`;
- чтение результата по каждому биту.

Мини-проверка:

```text
A = 11001010₂
B = 00110101₂
```

Вычисли `A & B`, `A | B`, `A ^ B` и объясни один выбранный разряд.

**Инвариант:** каждая побитовая операция обрабатывает разряды независимо.

**Переход:** результат получается не по запомненной таблице целого числа, а из правила для одного бита.

## Сессия 10B — слияние по маске

Пройди:

- формулу `(a & mask) | (b & ~mask)`;
- задачу 01-8;
- крайние маски `0` и `FFFFFFFFh`.

Мини-проверка:

```text
A = 11001010₂
B = 00110101₂
M = 11110000₂
```

Вычисли `(A & M) | (B & ~M)` и подпиши, откуда пришли старшие и младшие четыре бита.

**Инвариант:** каждый бит результата берётся из `a`, когда соответствующий бит маски равен `1`, иначе из `b`.

**Переход:** можешь объяснить, почему маска `0/1` не выбирает целое 32-битное значение.

<a id="сессия-10b-маска-0-1-и-выбор-без-ветвлений"></a>
## Сессия 10C — маска `0/-1` и выбор без переходов

Этот явный якорь сохраняет старые ссылки на прежнее название занятия.

Пройди:

- получение маски знака через `sar reg,31`;
- выбор между двумя 32-битными значениями;
- границу метода при переполнении разности;
- случай `INT32_MIN` для модуля.

Мини-проверка:

Напиши схему NASM, которая выбирает `negativeValue`, если `x < 0`, иначе `nonNegativeValue`, без `jcc`.

Проверь `x=-1`, `x=0`, `x=1`.

**Инвариант:** маска выбора полного слова должна быть `00000000h` или `FFFFFFFFh`.

**Переход:** можешь назвать вход, на котором знак переполненной разности не доказывает отношение двух чисел.

<a id="сессия-10c-ceil-и-деление"></a>
## Сессия 10D — безопасное округление вверх

Этот явный якорь сохраняет старые ссылки на прежнее название занятия.

Пройди:

- `ceil(a/b)` для `a >= 0`, `b > 0`;
- формулу `(a+b-1)/b` и её границу;
- безопасный вариант `q + (r != 0)` после `div`.

Мини-проверка:

Для `a=14`, `b=5` протрассируй оба способа. Затем объясни, почему `a=UINT32_MAX`, `b=2` разрушает безусловное использование суммы `a+b-1`.

**Инвариант:** безопасный вариант не создаёт промежуточную сумму, которой нет в исходной задаче.

**Переход:** можешь написать округление вверх через частное и остаток.

## Сессия 10E — прикладные задачи 01-14 и 01-15

### 01-14. Огород

Отдельно выведи:

```text
items
boxes
blocked
day
```

Проверь номера коробок `0,3,6,...` на маленьких значениях `boxes`.

### 01-15. Площадь

Отдельно выведи:

```text
det
absDet
integerPart
fractionDigit
```

Проверь `det=-9`, `det=8`, `det=0`.

Мини-проверка:

1. Для `boxes=7` выпиши все задержанные индексы и их количество.
2. Для `det=-9` получи строку `4.5` без вещественной арифметики.
3. Назови, почему обычный положительный `abs(INT32_MIN)` не помещается в `int32_t`.

**Переход:** можешь независимо объяснить арифметическую часть и часть выбора без ветвлений обеих задач.

## Сессия 10F — challenge 01-16

Эта сессия не является обязательной для перехода к Дню 11, если задача 01-16 не входит в ближайший контроль.

Пройди:

- независимость разрядов для `&` и `^`;
- четыре кандидата `(x_bit,y_bit)`;
- превращение результата одного бита в 32-битную маску подходящих позиций.

Мини-проверка:

Реши одну однобитную систему для всех четырёх кандидатов. Затем объясни, как те же логические выражения одновременно проверяют 32 позиции.

**Инвариант:** операции `&` и `^` не создают перенос между разрядами.

**Переход:** можешь восстановить смысл каждой кандидатной маски, а не только повторить готовую формулу.
