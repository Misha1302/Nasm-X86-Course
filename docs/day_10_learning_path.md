# День 10 как пять самостоятельных занятий

[Основная глава Дня 10](/day_10) содержит несколько разных навыков. Этот маршрут не добавляет теорию: он разделяет материал на занятия с отдельными условиями перехода.

## Правило перехода

Не переходи к следующей сессии, пока не можешь решить мини-проверку без подсказки. Просмотренное решение не считается закрытием.

## Сессия 10A — битовые операции и masked merge

Пройти в Дне 10:

- таблицу `and/or/xor/not/shl/shr/sar`;
- формулу `(a & mask) | (b & ~mask)`;
- задачу 01-8.

Мини-проверка:

```text
A = 11001010₂
B = 00110101₂
M = 11110000₂
```

Вычисли `(A & M) | (B & ~M)` и объясни результат побитно.

**Переход:** можешь объяснить, почему маска выбора целого слова должна содержать все нули или все единицы в выбираемых позициях.

## Сессия 10B — маска `0/-1` и branchless-выбор

Пройти:

- получение маски знака через `sar reg, 31`;
- выбор двух 32-битных значений;
- границу `INT32_MIN` для `abs`.

Мини-проверка:

Напиши NASM-shape, выбирающий `positiveValue`, если `x >= 0`, иначе `negativeValue`, без `jcc`. Укажи, где возникает маска `0/-1`.

**Переход:** на тестах `x=-1`, `x=0`, `x=1` выбирается правильное полное значение, а не один бит.

## Сессия 10C — `ceil` и деление

Пройти:

- `ceil(a/b)` для `a >= 0`, `b > 0`;
- вариант через частное и ненулевой остаток;
- переполнение `a+b-1`.

Мини-проверка:

Для `a=14`, `b=5` протрассируй оба способа. Затем объясни, при каком условии формула `(a+b-1)/b` безопасна и почему вариант через quotient/remainder не требует этой суммы.

**Переход:** можешь написать вариант, который не переполняет промежуточную сумму при допустимом 32-битном `a`.

## Сессия 10D — задачи 01-14 и 01-15

Пройти:

- 01-14: `boxes`, `blocked`, дневной и ночной ответ;
- 01-15: determinant, модуль и вывод `.0/.5`.

Мини-проверка:

1. Для `boxes=7` вручную посчитай количество индексов `0,3,6,...`.
2. Для `det=-9` получи `4.5` без floating point.
3. Назови границу обычного signed `abs`.

**Переход:** можешь независимо объяснить арифметическую формулу и branchless-часть обеих задач.

## Сессия 10E — challenge 01-16

Переходить сюда только после 10A–10D.

Нужно понять:

- `&` и `^` не переносят информацию между битами;
- один и тот же логический анализ выполняется параллельно для 32 позиций;
- для каждого бита есть четыре кандидата `(x_bit,y_bit)`.

Мини-проверка:

Реши руками одну 1-битную систему для всех четырёх кандидатов, затем объясни, как вместо одного бита получить 32-битную маску подходящих позиций.

**Переход:** можешь восстановить смысл каждой кандидатной маски, а не только повторить готовую формулу.
