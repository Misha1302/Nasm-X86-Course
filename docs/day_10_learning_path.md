# День 10 как шесть самостоятельных занятий

День 10 объединяет несколько разных навыков. Проходи занятия по порядку и не пытайся закрыть весь модуль одной сессией.

## Правило перехода

Переходи дальше, только если без подсказки можешь:

1. выполнить мини-проверку;
2. объяснить центральный инвариант;
3. назвать типовую ошибку и контрпример.

Просмотренное решение не считается попыткой.

## Сессия 10A — побитовые операции и слияние по маске

Изучи:

- `and`, `or`, `xor`, `not`;
- `shl`, `shr`, `sar`;
- формулу `(a & mask) | (b & ~mask)`;
- крайние маски `0` и `FFFFFFFFh`.

Мини-проверка:

```text
A = 11001010₂
B = 00110101₂
M = 11110000₂
```

Вычисли `A & B`, `A | B`, `A ^ B`, а затем `(A & M) | (B & ~M)`. Для результата подпиши источник каждого полубайта.

**Инвариант:** побитовые операции обрабатывают разряды независимо; каждый бит слияния выбирается соответствующим битом маски.

**Переход:** можешь объяснить, почему маска `0/1` не выбирает целое 32-битное значение.

<a id="сессия-10b-маска-0-1-и-выбор-без-ветвлений"></a>
## Сессия 10B — маска `0/-1` и выбор без переходов

Изучи:

- получение маски знака через `sar reg,31`;
- выбор между двумя 32-битными значениями;
- модуль через маску;
- границу метода при переполнении разности;
- особый случай `INT32_MIN`.

Мини-проверка:

Напиши схему NASM, которая выбирает `negativeValue`, если `x < 0`, иначе `nonNegativeValue`, без `jcc`. Проверь `x=-1`, `x=0`, `x=1`.

**Инвариант:** маска выбора полного слова равна либо `00000000h`, либо `FFFFFFFFh`.

**Переход:** можешь привести вход, на котором знак переполненной разности не доказывает отношение двух чисел.

## Сессия 10C — безопасное округление вверх

Сначала отдели математическую модель от машинного признака:

```text
a = q*b + r
0 <= r < b
ceil(a/b) = q + nonzero(r)
```

Для беззнакового 32-битного остатка `edx=r` получи `0/1` без `test`, `setcc`, `cmov` и переходов:

```asm
mov ecx, edx
neg ecx
or ecx, edx
shr ecx, 31
; ecx = 0 при r=0, иначе 1
add eax, ecx
```

**Доказательство:** для ненулевого 32-битного `r` хотя бы у одного из `r` и `-r` установлен старший бит; для нуля оба нулевые. После `or` и логического сдвига остаётся ровно признак `0/1`.

Обязательные тесты `r`: `0`, `1`, `2`, `0x7FFFFFFF`, `0x80000000`, `0xFFFFFFFF`.

Формула с предварительной суммой допускается только при отдельном доказательстве отсутствия переполнения.

**Порядок:** это первое объяснение машинного способа; обязательная практика идёт в 10D; первая оценка — `CP2-CEIL`.

## Сессия 10D — задача 01-14 «Огород»

Отдельно выведи `items → boxes → blocked → day`. Для каждого округления используй уже объяснённый безусловный признак остатка. В обязательной версии запрещены `jcc`, `setcc`, `cmov` и использование условных флагов как скрытого канала.

Проверь маленькие значения и вручную выпиши задержанные индексы `0,3,6,...`.

**Инвариант:** математическая модель, машинный `0/1` и выбор результата — разные доказуемые слои.

## Сессия 10E — задача 01-15 «Площадь»

Отдельно выведи:

```text
det
absDet
integerPart
fractionDigit
```

Проверь `det=-9`, `det=8`, `det=0`.

Мини-проверка:

Для `det=-9` получи строку `4.5` без вещественной арифметики и объясни границу `INT32_MIN`.

**Инвариант:** удвоенная площадь хранится целым числом; последняя цифра определяется чётностью модуля определителя.

## Сессия 10F — challenge 01-16

Эта сессия необязательна для перехода к Дню 11, если задача 01-16 не входит в ближайший контроль.

Изучи:

- независимость разрядов для `&` и `^`;
- четыре кандидата `(x_bit,y_bit)`;
- превращение результата одного бита в 32-битную маску подходящих позиций.

Мини-проверка:

Реши однобитную систему для всех четырёх кандидатов. Затем объясни, как те же выражения одновременно проверяют 32 позиции.

**Инвариант:** `&` и `^` не создают перенос между разрядами.

**Переход:** можешь восстановить смысл каждой кандидатной маски, а не повторить готовую формулу.
