# Как пройти курс самостоятельно

Эта страница — основной маршрут без преподавателя. Главы объясняют материал, [рабочая тетрадь](/transfer_workbook) проверяет перенос знаний на новые задачи, [диагностические ключи](/transfer_keys) помогают найти ошибочную модель, а [контрольные точки](/checkpoints) решают, можно ли идти дальше.

## Что считается самостоятельным прохождением

Глава закрыта не после чтения, а когда ты без подсказки можешь:

1. восстановить главную модель на бумаге;
2. решить соответствующую задачу `TR-XX`;
3. проверить себя по ключу с тем же номером;
4. назвать нарушенный инвариант и привести минимальный контрпример;
5. через день выполнить короткую проверку без перечитывания главы.

Фраза «вроде понятно» не является результатом.

## Цикл одной главы

### Шаг 1. Входная проверка — 3 минуты

Открой раздел `Входные знания` и попробуй выполнить перечисленные действия. Если одно не получается, перейди по указанной ссылке назад. Не начинай новую тему, пока необходимая предыдущая модель не восстановлена.

### Шаг 2. Первое чтение — 15–35 минут

1. Прочитай раздел `За 30 секунд`.
2. Нарисуй главную схему состояния.
3. Разбери решённый пример вручную.
4. Закрой объяснение и перескажи механизм своими словами.
5. Выполни практику главы.

Не открывай ответы до законченной попытки. Для практики без случайно раскрывающихся ответов используй [тетрадь без решений](/closed_book_workbook).

### Шаг 3. Следующий шаг — 10–25 минут

В конце каждого `day_XX.md` находится раздел `Следующий шаг` с двумя ссылками:

- задача `TR-XX` в [рабочей тетради](/transfer_workbook);
- ключ `TR-XX` в [диагностических ключах](/transfer_keys).

Задача отличается от примера главы. Сначала реши её полностью. Затем проверь обязательный результат, инвариант, типовую ошибку, контрпример и маршрут повторения.

### Шаг 4. Решение о переходе

| Результат | Что делать |
|---|---|
| Решение верно и каждый шаг объяснён | перейти к следующей главе |
| Одна локальная ошибка, основная модель верна | исправить ошибку и решить новый вариант |
| Нарушен центральный инвариант | вернуться к указанной предыдущей теме |
| Решение появилось только после просмотра ключа | решить новый вариант на следующий день |

Центральные инварианты курса: различие `x` и `[x]`, размер операнда, знаковая интерпретация, владелец флагов, пара `edx:eax`, границы массива, баланс `esp`, CDECL, глубина стека x87 и размер аргумента функции с переменным числом параметров.

## Контрольные точки

После каждого крупного раздела проходи [контрольную точку](/checkpoints):

| После | Что проверяется |
|---|---|
| Дня 04 | инструкции, регистры и размеры |
| Дня 10 | память, libc, деление и биты |
| Дня 15 | флаги, поток управления, таблицы переходов и адресация |
| Дня 19 | стек, CDECL, анализ машинного кода и структуры |
| Дня 23 | запуск программы, безопасность памяти, числа с плавающей точкой и x87 |
| Дня 24 | модель объектов C++ |

Каждое задание имеет постоянный номер `CP` и оценивается отдельно:

- `2` — полный правильный ответ с объяснением инварианта;
- `1` — основная модель верна, но есть одна локальная ошибка;
- `0` — основная модель неверна или отсутствует обязательный элемент.

У каждой контрольной точки указаны максимум, проходной балл и критические задания. Для перехода нужно набрать проходной балл и не получить `0` ни за одно критическое задание. После `1` реши дополнительный вариант из [ключей](/checkpoint_keys). После `0` сначала повтори указанную главу.

## Интервальное повторение

После каждой главы запланируй три коротких возврата:

| Когда | Что сделать |
|---|---|
| На следующий день | один вопрос из списка самопроверки и одна трассировка без конспекта |
| Через 3–4 дня | смешанное задание из прошлой главы |
| Через 7 дней | объяснить модель вслух и исправить ошибочный листинг |

Проверка в конце той же учебной сессии полезна, но не заменяет повторение через несколько дней.

## Журнал ошибок

После каждой существенной ошибки заполняй одну строку:

| Дата | ID | Мой ответ | Нарушенный инвариант | Минимальный контрпример | Что повторить | Вариант закрыт |
|---|---|---|---|---|---|---|
| | | | | | | |

Плохая запись: `ошибся в стеке`.

Хорошая запись: `CP4-STACK: после call считал [esp] первым аргументом; забыл адрес возврата; контрпример — push b, push a, call sum; повторить День 16; новый вариант решить завтра`.

## День 10 — пять отдельных занятий

Не пытайся пройти весь блок без переходов за один подход. Используй [маршрут Дня 10](/day_10_learning_path):

- `10A` — объединение по маске;
- `10B` — маска `0/-1`;
- `10C` — округление вверх и деление;
- `10D` — задачи 01-14 и 01-15;
- `10E` — усложнённая задача 01-16.

## Финальная готовность

Перед [пробным экзаменом](/day_25) проверь:

1. все шесть контрольных точек закрыты без нулей за критические задания;
2. не менее 20 из 25 задач `TR-XX` решены до просмотра ключа;
3. по последним ошибкам решены новые варианты;
4. ты можешь собрать и отладить программу в одной из [поддерживаемых сред](/support_matrix).

## Обучение вместе с нейросетью

Курс можно проходить с [ИИ-наставником](/ai_tutor_prompts). Есть режимы обучения с подсказками, строгого зачёта, восстановления после ошибок и разбора решения.

Название модели само по себе ничего не доказывает. Текущий статус и десять сценариев находятся на странице [Проверка ИИ-наставника](/ai_tutor_eval). Пока воспроизводимые запуски ChatGPT и DeepSeek не сохранены, подтверждена только структура инструкций.

Нейросеть не является источником истины. Канонические источники — условие, глава, реально собранный код, состояние машины и ключи.
