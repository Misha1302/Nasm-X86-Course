# Как пройти курс самостоятельно

Самостоятельность означает отсутствие скрытого шага: для каждого затруднения известно, что проверить, куда вернуться и каким новым действием доказать исправление.

Перед стартом выполни [входную диагностику](/prerequisites). Если действие не получается, открой точный раздел [коротких повторений](/prerequisite_refreshers).

## Цикл одной главы

### 1. Проверить входные знания

Выполни действия из раздела `Входные знания`. Не отмечай пункт по ощущению.

### 2. Прочитать короткую модель

После первого чтения закрой текст и ответь:

```text
какие объекты существуют;
где они находятся;
что меняет каждая инструкция;
какое условие должно сохраниться.
```

**Инвариант — условие, которое должно оставаться истинным в нужной точке программы.**

### 3. Протрассировать пример

Запиши начальное состояние, изменения после существенных инструкций и конечное состояние. Если промежуточный шаг приходится угадывать, вернись к абзацу, который вводит эту операцию.

### 4. Выполнить практику

Сначала реши задания без раскрытия `<details>`. Ответ считается готовым, если показаны вычисления или состояние машины, а не только итог.

### 5. Решить новую задачу

Перейди к `TR-XX` в [рабочей тетради](/transfer_workbook). Не открывай ключ до законченной попытки.

### 6. Использовать ключ по ступеням

Ключи курса имеют разные уровни подробности. Используй их в таком порядке:

1. **краткий диагностический ключ** — результат, инвариант, ошибка, контрпример;
2. **направляющий вопрос** — когда неясно, где искать расхождение;
3. **пошаговый разбор** — только если первая ошибка всё ещё не найдена;
4. **новый вариант** — обязательное доказательство исправления модели.

Для наиболее сложных задач доступны [пошаговые разборы TR-13, TR-17 и TR-23](/transfer_walkthroughs).

### 7. Записать первую точку расхождения

После проверки запиши:

- первую строку, где твоя модель разошлась с эталоном;
- нарушенный инвариант;
- минимальный контрпример;
- материал для повторения;
- результат нового варианта.

Фраза «невнимательность» не является диагнозом.

## Решение о переходе дальше

Переходи к следующей главе, если без подсказки можешь:

1. воспроизвести главную схему;
2. протрассировать минимальный пример;
3. решить `TR-XX`;
4. объяснить центральный инвариант;
5. разрушить типовую ошибку контрпримером.

Верный итог при неверной трассировке не закрывает тему.

## Интервальное повторение

| Когда | Что сделать |
|---|---|
| В той же сессии | практика и `TR-XX` |
| На следующий день | воспроизвести схему и решить короткий вариант |
| Через 3–4 дня | смешать тему с одной соседней |
| Через неделю | решить без подсказки и справочника |

Если возвращается прежняя ошибка, снова запиши инвариант и новый контрпример.

## Контрольные точки

После каждого блока пройди [контрольную точку](/checkpoints) без глав и ключей. Затем используй [зеркальные ключи и варианты](/checkpoint_keys).

Переход разрешён, когда:

- набран проходной балл;
- ни одно критическое задание не получило `0`;
- каждое задание с `1` закрыто новым вариантом.

## Граница оценок 2 / 1 / 0

### `2`

Итог, существенные промежуточные состояния и инвариант верны.

### `1`

Центральная модель верна, но есть одна локальная описка или несущественная ошибка.

### `0`

Неверно хотя бы одно состояние, от которого зависит механизм: направление операндов, адрес и значение, знаковость, глубина стека, баланс `esp` или порядок управления.

Пример: правильное число при утверждении, что `mov al,0` изменяет весь `eax`, получает `0`, потому что модель перекрывающихся регистров неверна.

## Журнал ошибок

| Дата | ID | Первая неверная строка | Инвариант | Контрпример | Что повторил | Новый вариант |
|---|---|---|---|---|---|---|
| | | | | | | |

Пример записи:

```text
Неверно: считал делимым только eax.
Инвариант: 32-битный idiv делит пару edx:eax.
Контрпример: одинаковый eax при edx=0 и edx=FFFFFFFF задаёт разные делимые.
```

## Особые маршруты

- [День 10](/day_10_learning_path) проходится как шесть отдельных занятий; обязательное ядро — 10A–10E.
- [CDECL и выравнивание](/c_abi) используют одну формулу для всей подготовленной области вызова.
- [Пошаговые разборы](/transfer_walkthroughs) открываются только после собственной попытки и краткого ключа.

## ИИ-наставник

[ИИ-наставник](/ai_tutor_prompts) может задавать вопросы и давать подсказки, но источниками истины остаются условие, материал курса и наблюдаемое состояние программы. При расхождении проверяй код, трассировку и канонический справочник, а не уверенность формулировки модели.
