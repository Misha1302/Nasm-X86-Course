# Как пройти курс самостоятельно

Эта страница — основной маршрут для обучения без преподавателя. Главы объясняют материал, [рабочая тетрадь](/transfer_workbook) проверяет перенос на новые задачи, а [контрольные точки](/checkpoints) решают, можно ли идти дальше.

## Что считается самостоятельным прохождением

Глава закрыта не после чтения, а когда ты без подсказки можешь:

1. восстановить главную модель на бумаге;
2. решить новую задачу из рабочей тетради;
3. назвать нарушенный инвариант в своей ошибке;
4. через день повторить короткий вопрос без перечитывания главы.

Фраза «вроде понятно» не является результатом.

## Цикл одной главы

### Шаг 1. Входной тест — 3 минуты

Открой раздел `Входные знания` и попробуй выполнить перечисленные действия. Если одно из них не получается, перейди по указанной ссылке назад. Не начинай новую тему на сломанной модели.

### Шаг 2. Первое чтение — 15–35 минут

1. Прочитай `За 30 секунд`.
2. Нарисуй главную схему или состояние.
3. Разбери пример руками.
4. Закрой объяснение и перескажи механизм своими словами.
5. Выполни практику главы.

Не открывай ответы до законченной попытки.

### Шаг 3. Перенос — 10–25 минут

Выполни задание соответствующего дня из [рабочей тетради](/transfer_workbook). Оно специально отличается от примера главы.

После попытки открой [ключи и диагностику](/transfer_keys). Запиши не только правильный ответ, но и правило, которое нарушил.

### Шаг 4. Решение о переходе

| Результат | Что делать |
|---|---|
| Решение верно, можешь объяснить каждый шаг | перейти к следующей главе |
| Одна локальная ошибка, модель верна | исправить и решить вариант из ключа |
| Ошибка в центральном инварианте | вернуться к указанному разделу главы |
| Решение получилось только после просмотра ответа | повторить перенос на следующий день |

Центральные инварианты курса: `x/[x]`, размер операнда, signed/unsigned, сохранность флагов, `edx:eax`, границы массива, баланс `esp`, CDECL, глубина x87-стека и размер variadic-аргумента.

## Контрольные точки

После блоков проходи [контрольные точки](/checkpoints):

| После | Контрольная точка |
|---|---|
| Дня 04 | Checkpoint 1 — инструкции, регистры, размеры |
| Дня 10 | Checkpoint 2 — память, ввод/вывод, арифметика, деление, биты |
| Дня 15 | Checkpoint 3 — флаги, control flow, jump table, адресация |
| Дня 19 | Checkpoint 4 — стек, CDECL, reverse, структуры |
| Дня 23 | Checkpoint 5 — startup, memory safety, floating point, x87 |
| Дня 24 | Checkpoint 6 — C++ object model |

Ответы и рубрики находятся отдельно в [ключах контрольных точек](/checkpoint_keys). Открывай их только после полной попытки.

## Интервальное повторение

После каждой главы запланируй три коротких возврата:

| Когда | Что сделать |
|---|---|
| На следующий день | один вопрос из чеклиста + один trace без конспекта |
| Через 3–4 дня | смешанное задание из прошлой главы |
| Через 7 дней | объяснить модель вслух и исправить один ошибочный листинг |

Каждый checkpoint уже является недельным смешанным повторением. Если курс проходится быстрее, всё равно не отменяй хотя бы одно отложенное воспроизведение.

## Журнал ошибок

Копируй одну строку после каждой существенной ошибки:

| Дата | Задание | Мой ответ | Нарушенный инвариант | Минимальный контрпример | Что повторить | Повтор закрыт |
|---|---|---|---|---|---|---|
| | | | | | | |

Плохая запись: `ошибся в стеке`.

Хорошая запись: `после call считал [esp] первым аргументом; забыл return address; контрпример — push b, push a, call sum; повторить День 16 и frame layout Дня 17`.

## День 10 — не один учебный день

Не пытайся пройти весь branchless-блок за один подход. Используй отдельный [маршрут Дня 10](/day_10_learning_path): пять занятий с мини-проверками от masked merge до challenge 01-16.

## Финальная готовность

Перед [mock exam](/day_25):

1. все шесть checkpoints закрыты без критических ошибок;
2. минимум 20 из 25 transfer-заданий решены без просмотра ключа;
3. последние ошибки в журнале имеют выполненный повтор;
4. можешь собрать и отладить программу в одной из [поддерживаемых сред](/support_matrix).

## Обучение вместе с нейросетью

Курс остаётся самодостаточным, но его можно проходить с AI-наставником. Готовые model-agnostic промпты для ChatGPT, DeepSeek и других моделей находятся на странице [AI-наставник](/ai_tutor_prompts).

Нейросеть не является источником истины. Канонические источники — глава курса, реально собранный код, состояние регистров/памяти/стека и ключи. Если объяснение модели противоречит исполняемому примеру или ABI курса, зафиксируй расхождение и проверь по материалу.
