# Популярные инструкции NASM x86

Канонический справочник команд находится на странице [Справочник основных инструкций NASM IA-32](/instruction_reference).

Эта страница сохранена как короткий совместимый указатель для старых ссылок. Не поддерживай здесь вторую копию таблиц: уточнения по `inc/dec`, `idiv`, знаковая/беззнаковая интерпретация-переходам, стеку и x87 должны редактироваться только в каноническом справочнике.

Для решения задач также используй:

- [Шаблоны кода](/code_patterns);
- [Карточки ошибок](/debug_cards);
- [Отладку в GDB](/debugging_with_gdb).
