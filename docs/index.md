# Как проходить курс

Этот сайт лучше читать не как длинную книгу, а как набор учебных модулей:

```text
правило -> схема -> шаблон -> пример -> ошибка -> практика
```

Главное правило курса:

> Если ты не можешь нарисовать, что происходит с регистрами, памятью, стеком или флагами после инструкции, тему ещё рано считать понятой.

## Как работать с главой

1. Прочитай блок `За 30 секунд`.
2. Проверь `Минимум после главы`.
3. Разбери главную схему.
4. Пройди базовый шаблон руками.
5. Сделай практику: trace, пропуски, написать самому, найти баг.
6. Отметь чеклист.

## Ускоренные маршруты с prerequisites

Маршрут — это ускорение для уже знакомого материала, а не независимый курс. Если входное условие не выполняется, пропущенная модель почти наверняка проявится в следующей задаче.


### Route A — быстро закрыть домашки

**Вход:** ты уже понимаешь регистры, `mov` и размеры `byte/word/dword`. Если нет — сначала пройди дни 03–04. Различие `x/[x]` вводится в самом Дне 05.


1. [День 05](/day_05) — `x` и `[x]`.
2. [День 06](/day_06) — `scanf` / `printf`.
3. [День 07](/day_07) — арифметика.
4. [День 08](/day_08) и [День 09](/day_09) — `cdq`, `idiv`, расширение знака.
5. [День 10](/day_10) — 01-4, 01-8, 01-14, 01-15, 01-16.
6. [Checkpoint 2](/checkpoints#checkpoint-2-после-дня-10) — проверить, что формулы не скрыли пробел в памяти, делении или signed/unsigned.

### Route B — подготовиться к листингам на экзамене

**Вход:** закрыт Route A или ты уверенно читаешь память, арифметику и signed/unsigned значения.


1. [День 11](/day_11) — флаги.
2. [День 12](/day_12) — `cmp`, `test`, `jcc`.
3. [День 13](/day_13) — `if`, циклы, GOTO-форма.
4. [День 14](/day_14) — `switch` и jump table.
5. [День 15](/day_15) — адресация и массивы.
6. [Checkpoint 3](/checkpoints#checkpoint-3-после-дня-15) — флаги, control flow и адресация.
7. [День 16](/day_16), [День 17](/day_17), [День 18](/day_18), [День 19](/day_19) — стек, CDECL, reverse и структуры.
8. [Checkpoint 4](/checkpoints#checkpoint-4-после-дня-19) — проверить frame layout и ABI-инварианты.

### Route C — добить продвинутые темы

**Вход:** уверенно пройдены адресация, стек, CDECL и структуры — дни 15–19.


1. [День 20](/day_20) — путь до `main`.
2. [День 21](/day_21) — ошибки памяти и защиты.
3. [День 22](/day_22) и [День 23](/day_23) — floating point и x87.
4. [Checkpoint 5](/checkpoints#checkpoint-5-после-дня-23) — startup, memory safety и floating point.
5. [День 24](/day_24) — C++ object model.
6. [День 25](/day_25) — mock exam.



## После базы: экзаменационные паттерны

Если задача уже не похожа на простую домашку, не надо сразу искать “ещё одну инструкцию”. Обычно нужен паттерн.

| Если в задаче | Открыть |
|---|---|
| запрещены переходы | [Branchless-маски](/patterns/branchless) |
| `K` битов, popcount, значащие нули | [Битовые циклы](/patterns/bit_counting) |
| палиндромы, дроби, GCD | [Десятичные алгоритмы](/patterns/decimal) |
| рекурсия без массивов | [Рекурсия](/patterns/recursion) |
| файлы, строки, libc | [Строки и файлы](/patterns/strings_files) |
| function pointer / varargs | [Advanced stack](/patterns/advanced_stack) |
| большой результат | [Big integer](/patterns/bigint) |

Краткие идеи по загруженным задачам собраны отдельно: [Идеи решений задач](/tasks/).

## Полный маршрут

- Дни 01–04: модель машины, инструкции и регистры. Затем [Checkpoint 1](/checkpoints#checkpoint-1-после-дня-04).
- Дни 05–10: память, первая программа, арифметика, деление, биты и Spring-01. Затем [Checkpoint 2](/checkpoints#checkpoint-2-после-дня-10).
- Дни 11–15: флаги, `cmp`, `test`, переходы, `switch`, адресация и массивы. Затем [Checkpoint 3](/checkpoints#checkpoint-3-после-дня-15).
- Дни 16–19: стек, функции, CDECL, reverse engineering и структуры. Затем [Checkpoint 4](/checkpoints#checkpoint-4-после-дня-19).
- Дни 20–23: запуск программы, безопасность, floating point и x87. Затем [Checkpoint 5](/checkpoints#checkpoint-5-после-дня-23).
- Дни 24–25: C++ object model и финальный mock exam.
- После экзамена: [отдельный маршрут x86-64](/modern_x86_64_next), чтобы не смешивать IA-32 CDECL с современным ABI.
