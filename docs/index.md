# Как проходить курс

Главный маршрут теперь состоит из четырёх разных слоёв:

```text
глава → новая задача → диагностика → отложенное повторение
                         ↓
                    checkpoint
```

Начни со страницы [Как пройти курс самостоятельно](/self_study). Она задаёт точный цикл главы, условия перехода, интервальное повторение и журнал ошибок.

## Цикл одной главы

1. Выполни `Входные знания` без подсказки.
2. Прочитай `За 30 секунд` и нарисуй модель состояния.
3. Разбери основной пример руками.
4. Выполни практику главы.
5. Реши задание своего дня в [рабочей тетради](/transfer_workbook).
6. Только после попытки открой [ключ](/transfer_keys).
7. Запиши нарушенный инвариант и реши, можно ли идти дальше.
8. На следующий день повтори один вопрос без конспекта.

Checkpoint оценивает отдельные навыки, а не выдаёт один непрозрачный балл за смешанное задание. Ноль по критическому инварианту блокирует переход независимо от суммы.

## Ускоренные маршруты с prerequisites

Маршрут — ускорение для уже знакомого материала, а не независимый курс. После каждого маршрута всё равно выполни transfer-задания и checkpoint.

### Route A — быстро закрыть домашки

**Вход:** понимаешь регистры, `mov`, размеры `byte/word/dword`. Если нет — дни 03–04.

1. [День 05](/day_05) — `x` и `[x]`.
2. [День 06](/day_06) — `scanf` / `printf`.
3. [День 07](/day_07) — арифметика.
4. [День 08](/day_08) и [День 09](/day_09) — расширение и деление.
5. [День 10](/day_10) через [пять отдельных сессий](/day_10_learning_path).
6. Transfer-задания Дней 05–10.
7. [Checkpoint 2](/checkpoints#checkpoint-2-после-дня-10).

### Route B — подготовиться к листингам

**Вход:** закрыт Route A или уверенно читаешь память, арифметику и signed/unsigned.

1. [День 11](/day_11) — флаги.
2. [День 12](/day_12) — `cmp`, `test`, `jcc`.
3. [День 13](/day_13) — GOTO-form.
4. [День 14](/day_14) — `switch` и jump table.
5. [День 15](/day_15) — адресация.
6. Transfer-задания Дней 11–15 и [Checkpoint 3](/checkpoints#checkpoint-3-после-дня-15).
7. [Дни 16–19](/day_16) — стек, CDECL, reverse, структуры.
8. Transfer-задания Дней 16–19 и [Checkpoint 4](/checkpoints#checkpoint-4-после-дня-19).

### Route C — продвинутые темы

**Вход:** уверенно пройдены адресация, стек, CDECL и структуры.

1. [День 20](/day_20) — путь до `main`.
2. [День 21](/day_21) — ошибки памяти и защиты.
3. [Дни 22–23](/day_22) — floating point и x87.
4. Transfer-задания Дней 20–23 и [Checkpoint 5](/checkpoints#checkpoint-5-после-дня-23).
5. [День 24](/day_24) — C++ object model.
6. Transfer Дня 24 и [Checkpoint 6](/checkpoints#checkpoint-6-после-дня-24).
7. [День 25](/day_25) — mock exam.

## Экзаменационные паттерны

Если задача уже не похожа на простую домашку, ищи не «ещё одну инструкцию», а паттерн.

| Если в задаче | Открыть |
|---|---|
| запрещены переходы | [Branchless-маски](/patterns/branchless) |
| `K` битов, popcount, значащие нули | [Битовые циклы](/patterns/bit_counting) |
| палиндромы, дроби, GCD | [Десятичные алгоритмы](/patterns/decimal) |
| рекурсия без массивов | [Рекурсия](/patterns/recursion) |
| файлы, строки, libc | [Строки и файлы](/patterns/strings_files) |
| function pointer / varargs | [Advanced stack](/patterns/advanced_stack) |
| большой результат | [Big integer](/patterns/bigint) |

Краткие идеи по задачам собраны отдельно: [Идеи решений задач](/tasks/).
