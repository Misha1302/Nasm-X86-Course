# Как проходить курс

```text
входная диагностика
        ↓
глава → практика → новая задача → диагностический ключ
                                      ↓
                                исправление модели
                                      ↓
                           отложенное повторение
                                      ↓
                              контрольная точка
```

## Главное правило

Тема закрыта не тогда, когда текст кажется знакомым, а когда ты можешь без конспекта:

1. нарисовать нужное состояние машины;
2. предсказать результат инструкций;
3. решить новую задачу;
4. назвать правило, которое сохраняется;
5. разрушить типовую ошибку минимальным контрпримером.
