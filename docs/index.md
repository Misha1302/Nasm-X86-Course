# Как проходить курс

Основной цикл:

```text
глава → новая задача → диагностический ключ → исправление → отложенное повторение
                             ↓
                      контрольная точка
```

Начни со страницы [Как пройти курс самостоятельно](/self_study).

## Цикл одной главы

1. Проверь входные знания.
2. Нарисуй главную модель состояния.
3. Разбери пример и выполни практику.
4. Открой раздел «Следующий шаг» в конце главы.
5. Реши соответствующую задачу `TR-XX` без ключа.
6. Сверься с ключом и запиши нарушенный инвариант.
7. При локальной ошибке реши новый вариант. При пробеле в понимании вернись к указанному материалу.
8. На следующий день коротко воспроизведи тему без конспекта.

## ИИ-наставник

Набор инструкций поддерживает обучение с подсказками, строгий зачёт, разбор непонимания, проверку решения и режим для короткого контекста. Само название модели ничего не доказывает. Текущее состояние проверки и десять поведенческих сценариев находятся на странице [Проверка ИИ-наставника](/ai_tutor_eval).
