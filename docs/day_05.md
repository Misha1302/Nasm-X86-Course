## За 30 секунд

- `x` обозначает адрес метки `x`.
- `[x]` обозначает значение в памяти по этому адресу.
- Квадратные скобки у обычной инструкции означают обращение к памяти.
- Размер `byte/word/dword` определяет, сколько соседних байтов читается или записывается.
- В IA-32 младший байт многобайтового числа лежит по меньшему адресу.

## Главная модель

Память — это массив байтов. У каждого байта есть адрес.

```text
адрес 0x1000 → один байт
адрес 0x1001 → следующий байт
адрес 0x1002 → следующий байт
```

Метка связывает имя с адресом:

```asm
section .data
    x dd 123
```

У `x` есть два разных смысла в коде:

| Запись | Смысл |
|---|---|
| `x` | адрес начала объекта |
| `[x]` | значение, прочитанное из памяти по адресу `x` |

Короткое правило:

```text
без скобок → работаем с адресом;
со скобками → идём по адресу в память.
```

---

## Разобранный пример

Пусть:

```asm
section .data
    x dd 123
```

Выполним инструкции независимо:

```asm
mov eax, x
mov ebx, [x]
lea ecx, [x]
mov [x], ebx
```

### `mov eax, x`

```text
eax = адрес x
```

Память не читается.

### `mov ebx, [x]`

```text
ebx = 123
```

Процессор читает четыре байта по адресу `x`.

### `lea ecx, [x]`

```text
ecx = адрес x
```

`lea` вычисляет адресное выражение, но не читает данные по этому адресу. Скобки здесь описывают формулу адреса, а не разыменование.

### `mov [x], ebx`

```text
память по адресу x = ebx
```

Происходит запись четырёх байтов, потому что размер источника `ebx` равен 32 битам.

Центральный инвариант:

> Адрес указывает, где лежат данные; значение является содержимым этих байтов. Это разные объекты состояния.

---

## Размер памяти

Ассемблеру иногда виден размер из регистра:

```asm
mov eax, [x]     ; читается dword, потому что eax 32-битный
mov [x], ax      ; записывается word, потому что ax 16-битный
```

Если регистра нет, размер может потребоваться указать явно:

```asm
inc dword [x]
```

Без `dword` непонятно, увеличить один, два или четыре байта.

## Секции данных

| Секция | Что хранится |
|---|---|
| `.text` | инструкции программы |
| `.data` | инициализированные изменяемые данные |
| `.rodata` | данные только для чтения, например строки формата |
| `.bss` | место под неинициализированные данные, которое загрузчик зануляет |

Пример:

```asm
section .data
    count dd 10

section .rodata
    message db "hello", 0

section .bss
    answer resd 1
```

`dd` создаёт четыре байта с начальным значением. `resd 1` резервирует место под один `dword`.

## Порядок байтов

IA-32 использует порядок от младшего байта к старшему (`little-endian`).

```asm
x dd 0x12345678
```

В памяти:

```text
адрес:   x      x+1    x+2    x+3
байт:   78      56     34     12
```

Число не «переворачивается». Меняется только порядок его байтов по возрастающим адресам.

## Практика

### 1. Адрес или значение

Для:

```asm
section .data
    n dd 17

mov eax, n
mov ebx, [n]
```

выпиши, что находится в `eax` и `ebx`.

<details>
<summary>Ответ</summary>

`eax` содержит адрес `n`, а `ebx` — значение `17`.

</details>

### 2. Найди чтение памяти

Какая инструкция действительно читает данные по адресу?

```asm
mov eax, x
lea ebx, [x]
mov ecx, [x]
```

<details>
<summary>Ответ</summary>

Только `mov ecx, [x]`.

</details>

### 3. Запиши один байт

Напиши инструкцию, которая записывает младший байт `eax` по адресу `buffer+3`.

<details>
<summary>Ответ</summary>

```asm
mov byte [buffer+3], al
```

</details>

### 4. Нарисуй память

Покажи четыре байта числа:

```text
0xA1B2C3D4
```

начиная с меньшего адреса.

<details>
<summary>Ответ</summary>

```text
D4 C3 B2 A1
```

</details>

## Типовые ошибки

| Ошибка | Почему неверно |
|---|---|
| считать `x` и `[x]` одинаковыми | первое — адрес, второе — содержимое памяти |
| считать, что `lea` читает память | `lea` только вычисляет адресное выражение |
| забыть размер записи | можно изменить лишние соседние байты или получить ошибку NASM |
| читать порядок байтов как обратную запись числа | порядок описывает размещение в памяти, а не текст числа |
| использовать стековый шаблон до объяснения | в этой главе для цели обучения стек не нужен |
