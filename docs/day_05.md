# День 05. `x` и `[x]`: адрес против значения

> **Важно для вызовов libc.** Перед `call` должно выполняться `esp % 16 == 0`. Выравнивающие байты и аргументы вместе должны занимать число байт, кратное 16. Подробности: [C ABI / CDECL](/c_abi) и [выравнивание стека](/patterns/libc_alignment).

## Опора на материалы ВШЭ

`Slides2026-02.pdf`, `Slides2026-04.pdf`: память, порядок байтов от младшего к старшему, секции `.data`, `.bss`, `.text`, статические данные и обращение к памяти.

## Входные знания

Перед началом проверь, что ты можешь:

- понимать регистры и размеры `byte/word/dword`;
- читать `mov destination, source`.

Если один из пунктов не получается объяснить или показать на маленьком примере, вернись к [Дню 04](/day_04).

## За 30 секунд

- `x` — адрес метки `x`.
- `[x]` — значение в памяти по адресу `x`.
- `mov eax, x` кладёт в `eax` адрес.
- `mov eax, [x]` читает значение.
- `mov [x], eax` записывает значение.
- `scanf` получает адрес: `push x`.
- `printf` получает значение: `push dword [x]`.

## Минимум после главы

Ты должен уметь:

- объяснить разницу между `x` и `[x]`;
- правильно вызвать `scanf("%d", &x)`;
- правильно вызвать `printf("%d", x)`;
- прочитать и записать `dword` в память;
- объяснить порядок байтов от младшего к старшему на числе `0x12345678`.

Можно пока не заучивать:

- `.got`, `.plt`, `.symtab`, `.strtab`;
- подробности перемещения адресов при компоновке;
- ELF-секции глубже `.text`, `.data`, `.bss`, `.rodata`.

## Главное правило

| NASM | C-похожий смысл | Что происходит |
|---|---|---|
| `x` | `&x` | адрес переменной |
| `[x]` | `x` | значение переменной |
| `mov eax, x` | `eax = &x` | адрес в регистр |
| `mov eax, [x]` | `eax = x` | значение в регистр |
| `mov [x], eax` | `x = eax` | запись в память |

Короткая привычка:

```text
видишь квадратные скобки -> идём в память по адресу
```

## Картинка памяти

```asm
section .data
    x dd 123
```

```text
address x
   |
   v
+----------------+
| 123            |
+----------------+
```

Теперь команды:

```asm
mov eax, x      ; eax = address of x
mov eax, [x]    ; eax = 123
mov [x], eax    ; memory[x] = eax
```

---

## Память как массив байтов

Можно думать так:

```cpp
uint8_t memory[...];
```

Адрес — это номер байта.

Если храним `dword`, он занимает 4 соседних байта.

---

## Секции NASM

| Секция | Что лежит |
|---|---|
| `.text` | код |
| `.data` | инициализированные изменяемые данные |
| `.bss` | зарезервированная зануленная память |
| `.rodata` | константы только для чтения, строки формата |

Пример:

```asm
section .data
    a dd 10
    b dd 20
    fmt db "%d", 10, 0

section .bss
    result resd 1
```

`a` и `b` уже имеют значения. `result` — место под будущий `dword`.

---

## Директивы данных

| Директива | Смысл | Пример |
|---|---|---|
| `db` | определить байт | `c db 10` |
| `dw` | определить слово, 2 байта | `s dw 1000` |
| `dd` | определить двойное слово, 4 байта | `x dd 123` |
| `dq` | определить четверное слово, 8 байт | `q dq 123456` |
| `resb` | зарезервировать байты | `buf resb 64` |
| `resw` | зарезервировать слова | `arr resw 10` |
| `resd` | зарезервировать двойные слова | `arr resd 10` |
| `resq` | зарезервировать четверные слова | `arr resq 10` |

## Порядок байтов от младшего к старшему

IA-32 хранит многобайтовые числа от младшего байта к старшему: младший байт лежит по младшему адресу.

```asm
section .data
x dd 0x12345678
```

В памяти:

```text
Address:   x      x+1    x+2    x+3
         +------+------+------+------+
Byte:    |  78  |  56  |  34  |  12  |
         +------+------+------+------+
```

Важно: это порядок байтов в памяти, а не порядок цифр в записи числа.

---

## `scanf`: нужен адрес

C:

```c
scanf("%d", &x);
```

NASM:

```asm
sub esp, 8       ; padding: 8 + 8 argument bytes = 16
push x
push fmtIn
call scanf
add esp, 16
```

Почему `x`?

Потому что `scanf` должен знать, куда записать число.

Плохо:

```asm
push dword [x]
```

`[x]` — старое значение переменной. Это не адрес для записи.

---

## `printf`: нужно значение

C:

```c
printf("%d", x);
```

NASM:

```asm
sub esp, 8       ; padding: 8 + 8 argument bytes = 16
push dword [x]
push fmtOut
call printf
add esp, 16
```

Почему `[x]`?

Потому что `printf` должен напечатать значение.

Плохо:

```asm
push x
```

Так ты напечатаешь адрес, а не число.

---

## Размер памяти: зачем `dword`

Иногда NASM понимает размер по регистру:

```asm
mov eax, [x]     ; eax 32-bit, читаем dword
```

Но иногда размер не очевиден:

```asm
inc [x]          ; byte? word? dword?
```

Нужно явно:

```asm
inc dword [x]
```

---

## Полный пример

```asm
section .data
    fmtOut db "%d", 10, 0
    x dd 123

section .text
    extern printf
    global main

main:
    push ebp
    mov ebp, esp
    and esp, -16
    sub esp, 8       ; padding: 8 + 8 argument bytes = 16
    push dword [x]
    push fmtOut
    call printf
    add esp, 16

    mov esp, ebp
    pop ebp
    xor eax, eax
    ret
```

Что важно:

| Строка | Смысл |
|---|---|
| `push dword [x]` | положить значение `123` |
| `push fmtOut` | положить адрес строки формата |

---

## Частые ошибки

| Ошибка | Почему плохо | Как правильно |
|---|---|---|
| `push [x]` для `scanf` | передаёшь значение вместо адреса | `push x` |
| `push x` для `printf("%d")` | печатаешь адрес вместо значения | `push dword [x]` |
| `push [fmtOut]` | передаёшь первые 4 байта строки как адрес | `push fmtOut` |
| думать, что `[x]` — адрес | наоборот: это значение по адресу | `x` — адрес, `[x]` — значение |
| забыть порядок байтов | неправильно читаешь число в памяти | младший байт лежит первым |
| не указать `dword` там, где размер неясен | NASM не знает размер операции | `inc dword [x]` |

## Практика

### A. Трассировка

Что будет в регистрах?

```asm
section .data
    x dd 123

mov eax, x
mov ecx, [x]
```

Заполни:

| Регистр | Значение |
|---|---|
| `eax` | ? |
| `ecx` | ? |

<details>
<summary>Ответ</summary>

`eax` получает адрес `x`.

`ecx` получает значение `123`.

</details>

### B. Заполни пропуски

```asm
; scanf("%d", &x)
push ___
push fmtIn
call scanf
add esp, ___
```

<details>
<summary>Ответ</summary>

```asm
sub esp, 8       ; padding: 8 + 8 argument bytes = 16
push x
push fmtIn
call scanf
add esp, 16
```

</details>

### C. Напиши сам

Есть переменная:

```asm
x resd 1
```

Напиши фрагмент, который печатает `x` через `printf("%d\n", x)`.

<details>
<summary>Ответ</summary>

```asm
sub esp, 8       ; padding: 8 + 8 argument bytes = 16
push dword [x]
push fmtOut
call printf
add esp, 16
```

</details>

### D. Найди баг

```asm
sub esp, 8       ; padding: 8 + 8 argument bytes = 16
push dword [x]
push fmtIn
call scanf
add esp, 16
```

Что не так?

<details>
<summary>Ответ</summary>

Для `scanf` нужен адрес `x`, а не значение `[x]`.

</details>
